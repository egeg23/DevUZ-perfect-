# Ежедневный разбор

Один разбор в день. Не два, не ноль. Работа считается сделанной, когда
открыт PR со статьёй и двумя парами скриншотов, а не когда «почти готово».

Прежде чем писать текст — прочитай `.claude/skills/seo-razbor/SKILL.md`.
Там правила подбора запроса, структуры и того, чего не пишем никогда. Этот
файл про порядок действий, тот — про содержание.

## 0. Что уже сделано

```
psql/Supabase: select category, city, status from razbors;
```

Список опубликованных — в `content/razbor/items.ts`. Выбери пару
**ниша + город**, которой там ещё нет. Каталог пар — в
`content/razbor/catalog.ts`: 14 ниш на 12 городов, 336 сочетаний, так что
повторяться незачем ещё очень долго.

Приоритет городов: Ташкент и другие города Узбекистана вперёд, Алматы,
Астана, Шымкент, Бишкек и Ош — реже. Узбекистан домашний рынок, и разборов
по нему должно быть больше.

## 1. Найти сайт

Поиском (WebSearch) по выбранной паре: «стоматология Ташкент», «автосервис
Самарканд». Нужен сайт живого малого бизнеса, а не каталог, агрегатор,
маркетплейс или страница в соцсети.

**Не берём:**

- государственные сайты и всё, что связано с политикой;
- банки, клиники с лицензируемой медициной в названии услуги, аптеки —
  там ошибка в формулировке дороже, чем польза от статьи;
- сайты наших клиентов и наших партнёров (сверься со списком проектов);
- сайты, которые уже разбирали — проверь `source_hash` в `razbors`.

## 2. Проверить и решить

```
node --experimental-strip-types -e '…'   # или через lib/audit/fetch.ts + checks.ts
```

Прогони `probe()` и `analyze()` из `lib/audit`. Дальше решает
`worthWriting()` из `lib/razbor/model.ts`:

| Вердикт | Что делать |
|---|---|
| `ok` | пишем разбор |
| `unreachable` | сайт не открылся — берём следующий |
| `thin` | меньше трёх находок — берём следующий |
| `too_good` | сайт нормальный — берём следующий |

Отклонённый сайт всё равно запиши в `razbors` со статусом `rejected` и
причиной: иначе через неделю ты вернёшься к нему снова.

**Не подгоняй вердикт под желание написать статью.** Разбор нормального
сайта читатель распознаёт за абзац, и дальше он не верит ни одному
разбору на сайте.

## 3. Снимки

```
node scripts/razbor-shot.mjs <адрес> public/razbor/<slug>
node scripts/razbor-mock.mjs <ниша> <город> ru public/razbor/<slug>
node scripts/razbor-mock.mjs <ниша> <город> uz public/razbor/<slug>
```

Первый снимает живой сайт и закрывает имя и логотип плашками. **Открой
получившийся PNG глазами.** Скрипт возвращает `covered` — сколько плашек
поставил; ноль означает, что имя на первом экране не нашлось, и это повод
посмотреть внимательно, а не повод пропустить проверку.

Если на снимке осталось название компании — не публикуй. Добавь слово
руками через третий аргумент или выбери другой сайт.

Файлы переименуй под адрес статьи и положи в `public/razbor/<slug>/`.

## 4. Текст

По правилам из `seo-razbor`. Коротко о главном:

- **Один запрос на страницу**, с нишей и городом. Возьми готовый из
  `queryFor()`, не выдумывай свой.
- **Русская и узбекская версии — разные тексты под разные запросы.** Не
  перевод. Узбекский — латиницей.
- **Заголовок находки — следствием**: «на телефоне сайт открывается в
  масштабе большого экрана», а не «отсутствует meta viewport». Находки
  бери из `analyze()`: там уже готовые `title`, `impact`, `fix`
  человеческим языком.
- **Никаких выдуманных цифр.** Если числа нет — пиши «обычно» и диапазон.
- **Компанию не называем.** Подпись — из `labelFor()`.

Запиши статью в `content/razbor/items.ts` двумя объектами (ru и uz),
связанными через `alt`.

## 5. Проверить себя

```
npx tsc --noEmit && npm test && npm run build
```

Плюс глазами: открой `/ru/razbor/<slug>` локально и посмотри, что оба
снимка на месте, подписи не разъехались, а телефонный снимок макета
читается.

## 6. Отдать

Коммит в ветку `claude/devuz-studio-website-ydhj10`, затем PR. В описании:
ниша, город, запрос, сколько находок, и одной строкой — почему этот сайт.

**Не мержи сам.** Разбор выходит под именем студии, и последнее слово за
владельцем. После PR напиши ему в Telegram ссылку.

## Когда работать нечего

Бывает: три сайта подряд оказались нормальными или недоступными. Это не
повод понизить планку. Запиши отклонённые в `razbors`, напиши владельцу
одной строкой, что сегодня разбора не будет и почему, и заканчивай.

Пустой день честнее выдуманного разбора.
