## YouTube: `yt-*`

Владелец, 19.10.2026: «берем 1 который ты советуешь, устанавливаем его к
нам». Одиннадцать навыков и шесть инструментов на чистом Python без
зависимостей, MIT. Сеть они не трогают и сами ничего не публикуют: пишут
текст, человек выкладывает.

| Команда | Что делает |
|---|---|
| `/yt-viral` | что заходит в нише: видео по кратности к медиане своего канала (`swipe.py`) |
| `/yt-script` | сценарий: 5 вариантов первых секунд по 21 формуле с оценкой (`hookscore.py`) |
| `/yt-package` | название и обложка одной парой: обрезка, повтор, расплывчатость (`title.py`) |
| `/yt-edit` | из расшифровки — что вырезать: паузы, повторы, дубли (`deadair.py`) |
| `/yt-retention` | выгрузка удержания: где уходят зрители и почему (`retention.py`) |
| `/yt-chapters` | главы по правилам YouTube (`chapters.py`) |
| `/yt-shorts`, `/yt-seo`, `/yt-comment`, `/yt-plan`, `/yt-audit` | Shorts из длинного, описание, ответы на комментарии, план недели, разбор канала |

- Голос канала — `~/.claude/youtube/voice.md`, его читает каждый навык;
  шаблон — `yt-script/voice-template.md`. В облачной сессии домашняя папка
  не живёт дольше сессии: голос клиента держим у себя и кладём в начале
  работы.
- 21 формула заголовков — английские шаблоны: на русском и узбекском
  `/yt-viral` верно считает кратность, но формулу подписывает
  «Unclassified» — её называет сама сессия.
- Список видео для `/yt-viral` — `yt-dlp --flat-playlist -J`, публичная
  страница или руками; из облака YouTube такие запросы может не пускать.

## Instagram: `ig-*`

Владелец, 19.10.2026: «то же самое для инстаграм». Тот же автор, тот же
подход: тринадцать навыков, пять инструментов на чистом Python, MIT. Сеть не
трогают, в Instagram не входят, пароль не спрашивают, сами ничего не
публикуют.

| Команда | Что делает |
|---|---|
| `/ig-viral` | что заходит в нише: рилсы по кратности к медиане своего аккаунта, формула первой фразы, файл образцов (`swipe.py`) |
| `/ig-reel` | рилс из идеи: 3 первые фразы из 26 формул с оценкой, текст, надписи, раскадровка по секундам (`hookscore.py`, `beats.py`) |
| `/ig-caption` | подпись: что видно до «ещё», одна просьба, три хештега (`caption.py`) |
| `/ig-human` | чистит текст от следов модели: длинные тире, штампы, невидимые символы (`humanize.py`, `detect.py`) |
| `/ig-carousel`, `/ig-story`, `/ig-profile`, `/ig-plan` | карусели 1080×1350, сторис, профиль по 12 пунктам на 100 баллов, план недели |
| `/ig-comment`, `/ig-reply`, `/ig-dm`, `/ig-repurpose`, `/ig-audit` | комментарии у других, ответы у себя, личные сообщения, видео в неделю постов, разбор уже вышедшего |

- Голос аккаунта — `~/.claude/instagram/voice.md`, шаблон —
  `ig-reel/voice-template.md`; в облаке, как и у YouTube, кладём в начале
  работы.
- `/ig-viral` смотрит аккаунты руками, через браузер сессии: 6-12 аккаунтов
  по дюжине рилсов. Сборщик и чужие сервисы сбора навык запрещает сам —
  массовый сбор нарушает правила Instagram и ведёт к блокировке.
- Формулы и словарь штампов `/ig-human` — английские: на русском и узбекском
  тире и невидимые символы он ловит, штампы — нет; их держит наш
  `lib/proto/plain-text.ts`.

## TikTok: `tt-*`

Владелец, 19.10.2026: «И для тик ток погнали тоже, под разные аудитории
планирую выпускать видосы, чтобы как-то продвигать студию». Набор Ian Ryan
Kirk по образцу `ig-*` (часть инструментов взята оттуда, обе лицензии MIT —
в `LICENSE`). Двенадцать навыков, инструменты на чистом Python, без сбора с
TikTok и без публикации.

| Команда | Что делает |
|---|---|
| `/tt-hook` | первые 1-3 секунды в три слоя: что сказать, что написать на экране, что показать; 20 формул с оценкой (`hookscore.py`) |
| `/tt-script` | сценарий и раскадровка по секундам: зацепка до 3 с, длина, петля (`beats.py`) |
| `/tt-trends` | что растёт, что на пике, что уходит: по выгрузке трендов, которую вставляем сами (`trends.py`) |
| `/tt-viral` | что заходит в нише по кратности к медиане аккаунта (`swipe.py`, берёт `../tt-hook`) |
| `/tt-caption`, `/tt-seo` | подпись и надпись на экране (`caption.py`, перенос в Shorts и Reels — `crosspost.py`); поисковые слова и вопросы зрителей (`kwmap.py`, `questions.py`) |
| `/tt-plan` | месяц роликов, снятых за один-два часа съёмки |
| `/tt-retention`, `/tt-profile`, `/tt-comment`, `/tt-repurpose`, `/tt-human` | удержание, профиль, комментарии, перенос длинного в короткое, чистка текста |

- Голос — `~/.claude/tiktok/voice.md`, шаблон — `tt-script/voice-template.md`.
  Шаблон месяца, который `/tt-plan` зовёт `templates/month.md`, лежит в
  `tt-plan/month-template.md`.
- Все двенадцать папок ставятся вместе: `/tt-viral` читает соседний
  `tt-hook`.
- Монтаж — не здесь, а HyperFrames (`/hyperframes:hyperframes`,
  `talking-head-recut`, `embedded-captions`) и FFmpeg. Навык
  `Yuvalkesh/viral-tiktok-editor` смотрели и не взяли: он под macOS, иврит и
  CapCut.

Последние два взяты под задачу «сделай первое касание таким, как у топовых
студий». Из них взята **рамка** — что вообще смотрят и в каком порядке, — а
пороги и формулировки написаны заново в `lib/audit/deep.ts`. Чужие пороги на
узбекский рынок не переносятся, а чужие формулировки написаны для отчёта,
который читает маркетолог, а не владелец мебельного цеха.

Скопированы целиком только две ветки: `cro` из первого и `seo-audit` с
`seo-technical` из второго. Тянуть репозиторий на сотню навыков ради двух
значило бы принести в дерево код, который никто здесь не читал.

Владелец: «используй всегда» — про `ui-ux-pro-max`. Тесты этого навыка из
копии убраны: они проверяют его собственные данные, а не наш код, и в нашем
прогоне только шумели бы.

## Плагином, а не копией: HyperFrames

[heygen-com/hyperframes](https://github.com/heygen-com/hyperframes)
(Apache 2.0) — видео из HTML: промо-ролик по сайту клиента, моушн-графика,
объясняющее видео, субтитры, интерактивные презентации. Владелец, 28.09:
«устанавливаем и используем для наших клиентов в разработке».

Подключён плагином через `.claude/settings.json` (`extraKnownMarketplaces` +
`enabledPlugins`), а не скопирован сюда, и это осознанно: навыки завязаны на
версию его CLI, которая обновляется почти каждый день и скачивается при
каждом запуске. Копия разошлась бы с ней за неделю. Claude Code при открытии
репозитория ставит плагин сам; вход — `/hyperframes:hyperframes`, дальше он
сам выбирает сценарий (`product-launch-video`, `motion-graphics`,
`slideshow`, `faceless-explainer`, `embedded-captions` и т. д.).

Что внутри: 21 навык, ни хуков, ни MCP-серверов, около 4 тыс. токенов на
каждую сессию (`claude plugin details hyperframes@hyperframes`).

Чтобы рендерить:

- Node 22+, FFmpeg и Chrome. Chrome ставится командой
  `npx hyperframes browser ensure`; FFmpeg — системный или `ffmpeg-static`
  из npm (путь к бинарнику положить в `PATH`). Проверка — `npx hyperframes doctor`.
- **Телеметрию выключать:** `DO_NOT_TRACK=1` в окружении или
  `npx hyperframes telemetry disable`. Работа идёт с материалами клиентов.
- Проект ролика — отдельная папка (`npx hyperframes init <имя>`), не внутри
  этого репозитория и не на сервере сайта: рендер грузит процессор, а сайту
  нужен тот же сервер.
- Цифры о студии в роликах — из `content/company.ts`, как в презентациях
  партнёра; о клиенте — только из его сайта и брифа.
