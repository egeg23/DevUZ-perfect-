# 3D-страница товара: разлёт на детали по прокрутке

Рецепт из ролика, который прислал владелец 21.10.2026 («Сохрани это перед
своей следующей 3D-страницей товара»). Первый макет по нему — SamAuto,
D-MAX IRBIS LSE: `scripts/protos/samauto/` (сцена — `scene.src.js`,
детали — `segment.py`, фото на модели — `photo/`, README там же).

## Рецепт

1. **Модель на части.** Разбиение на части в Tripo или каждая деталь
   отдельно, с уникальным именем. Одна сетка — одна часть. Нет разбиения —
   режем сами по координатам (`segment.py`): колёса, двери, капот, передок,
   фары, зеркала, крыша, кузов.
2. **При загрузке** у каждой части запомнить начальное место и направление
   от центра модели: оба центра — `new THREE.Box3().setFromObject(obj)
   .getCenter(new THREE.Vector3())`, вычесть, нормализовать.
3. **Всё ведёт одно число** `explode` от 0 до 1, привязанное к прокрутке.
4. `position = start + direction * explode * шаг`. Каждой части — случайный
   множитель 0.7-1.3, выбранный один раз (с зерном: раскладка одинаковая при
   каждом открытии), чтобы взрыв не был идеальным. Шаг в ролике 1.5 — для
   модели в метрах; у модели длиной ~1 шаг меньше (у SamAuto 0.3).
5. **Маленькие части летят дальше:** умножить на `clamp(1 / size, 0.5, 2)`,
   size — размер части, делённый на размер всей модели.
6. **Немного вращения:** случайный угол до 0.6 рад, умноженный на `explode`.
7. **Прокрутку — через power2.inOut**, чтобы у 0 и у 1 детали стояли. Поверх
   — damp, чтобы не дёргались.
8. **Сборка обратно — бесплатно:** та же формула, `explode` идёт от 1 к 0.
9. **Число деталей — настоящее:** посчитать меши через `scene.traverse` и
   вывести на страницу. Настоящее количество лучше выдуманного.

## Что ещё выяснилось на SamAuto

- Модель из одного фото (Tripo, Meshy) бывает с неверными пропорциями: у
  D-MAX она вышла на 22% короче. Сверять с настоящими размерами и тянуть по
  участкам, оставляя колёса круглыми.
- Фотореализм — снимки на модели, а не краска генератора: камеры снимков по
  опорным точкам (solvePnP), запекание с учётом видимости, зеркальный снимок
  на другой борт, внутренности тёмные (`photo/`, README).
- Без WebGL, при reduced motion и экономии трафика — кадры той же сцены, не
  белый экран. Модель сжата meshopt, текстуры WebP: 2-3 МБ на телефон.
- Прокрутку не перехватывать: сцена только читает долю пройденного.
- `.glb` в `public` — расширение в исключениях `middleware.ts`, иначе
  уходит в языковой редирект.
