# Промпты плановых смен

Здесь лежат тексты, которыми запускаются плановые смены (Routines в
claude.ai/code). Сам текст хранится не здесь, а в хранилище рутин — здесь
его копия, и вот зачем она нужна.

Рутина невидима из репозитория: её нельзя открыть, нельзя сравнить с
прошлой версией и нельзя восстановить, если она потерялась. Два дня
разборов пропали ровно потому, что промпт начинался с `git fetch origin main`
в сессии, где репозитория нет, — и увидеть это можно было только открыв
рутину в браузере.

Правило простое: правишь рутину — правь и файл здесь, тем же коммитом.
Расходиться им нельзя; тест `tests/shift-reports.test.ts` стережёт, что
обязательные куски (бутстрап репозитория и строка в `shift_reports`) в
файлах остались.

| Файл | Рутина | Запуск |
|---|---|---|
| `razbor-daily.md` | Разборы конкурентов: три в день | 03:03 UTC = 08:03 Ташкент |
| `experiment-300-2000.md` | Эксперимент 300→2000 | 04:05 UTC = 09:05 Ташкент |

Почему смены вообще начинают с того, что достают себе репозиторий: плановая
сессия стартует в пустой папке. `pwd` даёт `/home/user`, `git rev-parse` —
`fatal: not a git repository`. Репозиторий к ней не приложен, и достать его
она должна сама, через `add_repo` и `register_repo_root`.
