## Шаг 0. Достань себе репозиторий

Плановая сессия стартует в ПУСТОЙ папке: `pwd` даёт `/home/user`, `git rev-parse` — `fatal: not a git repository`. Именно поэтому с 13 сентября в ветке эксперимента нет ни одного коммита, хотя смены отмечались «успешными»: первая же команда падала. Поэтому первым делом — репозиторий.

    pwd; git -C /home/user/DevUZ-perfect- rev-parse --show-toplevel 2>&1 | tail -1

Если ответ не `/home/user/DevUZ-perfect-`, достань его:

1. Вызови инструмент `add_repo` (сервер claude-code-remote): owner `egeg23`, repo `DevUZ-perfect-`, access `push`. Не проверяй репозиторий заранее через curl или git ls-remote: приватный отвечает «404 Not Found» даже когда доступ есть, и ты решишь, что его нет.

3. Вызови `register_repo_root`: owner `egeg23`, repo `DevUZ-perfect-`, directory `/home/user/DevUZ-perfect-`. Без этого навыки и CLAUDE.md из репозитория не подхватятся.
4. Убедись, что получилось:

## Шаг 2. Веди смену

Двигай план, а не спрашивай, что делать: владелец — наблюдатель и оценщик, он специально просил свести своё участие к минимуму. В `HUMAN_QUEUE.md` клади только то, что ты действительно не вправе сделать сам. Если очередь человека висит непрочитанной вторую смену, не жди её: делай то, что от неё не зависит.

Если факты разошлись со ставкой из PLAN.md — меняй ставку и запиши почему.

На сервер выкатывается только main. Любая правка кода приложения делается в этой ветке, но не считается сделанной, пока не попала в main: в конце смены открой pull request из `claude/300-to-2000-experiment-xuir3p` в main (`mcp__github__create_pull_request`), дождись зелёного CI и смержи его сам (`mcp__github__merge_pull_request`). Никогда не пуши в main напрямую и никогда не переписывай историю ни одной ветки. Если смена меняла только `experiment/`, PR не нужен — но push в свою ветку обязателен.

Инструменты базы в этой сессии могут называться не `mcp__Supabase__…`, а `mcp__<uuid>__…`. Ищи их через ToolSearch по имени — `execute_sql` — а не по префиксу.

## Шаг 3. Запись и отчёт — последнее действие смены

Смена заканчивается записью, а не работой.
