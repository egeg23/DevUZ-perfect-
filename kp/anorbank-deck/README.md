# Презентация для ANORBANK: два концепта нового сайта

Владелец, 04.11.2026: «Нужно подготовить 2 КП: на русском и узбекском. У них
устарел дизайн сайта. Пока без цен… Надо сделать 2 концепта», и следом:
«Давай сделаем 2 концепта в рамках одного документа просто. Типа можем так,
а можем вот так». Цен в документе нет: сроки и стоимость — после выбора.

- Концепт 1 «Ясный» / «Tiniq» — светлый, «Что сделаем сегодня?» с
  подсказками, продукты карточками, калькулятор вклада, нижняя панель на
  телефоне. Концепт 2 «Гранат» / «Anor» — тёмный премиум, раскрытый гранат,
  зёрна-услуги по прокрутке, Anor Premium веером.
- `concepts/c1.tpl.html`, `concepts/c2.tpl.html` — вёрстка концептов,
  тексты — `concepts/text.json` (ru и uz, узбекский — латиница, «‘»).
  Картинки `concepts/img/` — Higgsfield (gpt_image_2_5, 4 кадра, 1 кредит),
  знак банка вырезан из иконки их приложения в App Store.
- `shots.mjs` → `img/ru`, `img/uz` (собирает `concepts/<c>.<язык>.html`, они
  в `.gitignore`); `build.mjs` → `anorbank-ru.html`, `anorbank-uz.html`;
  `pdf.mjs` → `kp/anorbank-ru.pdf`, `kp/anorbank-uz.pdf`, 14 слайдов 1600×900,
  падает, если текст залез на подвал.
- Шрифты — `kp/fonts-anorbank.css` (Montserrat, Inter, Unbounded), сеть не
  нужна.

Цифры и названия услуг — только с anorbank.uz и из их приложения на
04.11.2026: «до 50 млн сум за минуту», «доставка карты за 72 часа»,
«переводы без комиссии до 100 млн сум в месяц», 4,7 в App Store (5 896
оценок). Доход по вкладу в калькуляторе помечен «для примера». Сайт банка с
зарубежных адресов отвечает 403: открылась только главная (HTML), поэтому
снимка «как сейчас» в документе нет; факты аудита — по коду главной.
