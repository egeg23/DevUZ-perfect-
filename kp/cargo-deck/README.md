# Презентация для карго-компаний

С ней менеджер выходит на логистов (владелец, 03.11.2026). Показывает макет
`scripts/protos/cargopro` целиком: сайт с расчётом, кабинет клиента с Telegram,
обычную админку и супер-админку (распределение, водители, сборные грузы,
автопарк, пакет для брокера, интеграции, настройки), выгоду, «почему сейчас»,
опыт Lider Cargo (LBM Driver), цены и шаги.

- `build.mjs` → `cargo-ru.html`, `cargo-uz.html` (цены берутся из `plan.mjs` макета).
- `pdf.mjs` → `kp/cargo-ru.pdf`, `kp/cargo-uz.pdf`, 18 слайдов 1600×900; падает, если текст залез на подвал.
- `img/ru`, `img/uz` — экраны макета **без бренда клиента**: «YOUR CARGO», нейтральный
  знак, примерные телефоны и адрес, номера заказов `YC-`. Чужой знак в нашей рекламе без
  договора не ставим (proto-master §5).

Переснять экраны: собрать макет (`node scripts/protos/cargopro/gen.mjs`), запустить
`SCENE_KEY=… node kp/cargo-deck/serve-neutral.mjs` (порт 4853, как у `serve.mjs`) и
прогнать `scripts/protos/cargopro/shots.mjs` по режимам (`""`, `dispatch`, `route`,
`super`, `client`, `settings`) на 1440 и 390; для узбекской версии — та же
`shots.mjs` с путями `/uz/…`. Затем нарезать нужные кадры в `img/<язык>/` (JPEG, 1440×900
и телефон 585 px).

Цифры выгоды — демо-рейс макета (−31,9 км, −36%) и примеры с подписанными
допущениями (100 рейсов × 1 ч × 15 $; 40 звонков × 3 мин). Это не обещания.
