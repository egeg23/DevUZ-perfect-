# Коммерческие предложения

КП свёрстано, а не набрано в редакторе: правка цены — правка строки, а не
перерисовка макета, и через минуту готов новый PDF. Палитра и гарнитуры
берутся не с нашего сайта — заказчик смотрит на документ, чтобы увидеть свой
будущий сайт, а не нашу студию.

| Файл | Для кого |
| --- | --- |
| `mavera.html` | Исходник. Открывается в браузере, правится текстом. |
| `mavera.pdf` | То, что уходит клиенту в мессенджер. |

Клиенту отправляем PDF, а не ссылку: ссылку он не откроет с чужого телефона,
а файл перешлёт руководителю.

## Собрать заново

```
node scripts/kp-pdf.mjs kp/mavera.html kp/mavera.pdf
```

Скрипт меряет каждый лист и возвращает ненулевой код, если тот перерос A4.
Лист, выросший хотя бы на пиксель, в PDF разрывается пополам: вторая половина
уезжает на пустую страницу с обрезанным подвалом, и смета оказывается на
развороте. Поэтому проверка машинная, а не «посмотрел и вроде влезло».

Шрифты лежат в `kp/fonts/` и подключаются из `kp/fonts.css`. Пересобирать их
нужно, только если меняется набор гарнитур:

```
node scripts/kp-fonts.mjs
```

## Как устроена вёрстка

Документ собран листами A4 (`.sheet`), а не сплошным потоком. Так экранная
версия и PDF ломаются по страницам одинаково: то, что видно в браузере, и
есть то, что уйдёт клиенту. Открывающий и закрывающий листы тёмные, рабочие —
на кремовой бумаге: КП печатают в отделе продаж, и пять тёмных страниц там
превращаются в пять листов расхода тонера.

Нумерация страниц в подвалах проставлена руками. Автоматической её делать
нечем: `@page` считает страницы, но достать счётчик в разметку нельзя.
Добавили лист — поправьте `N / 5` во всех подвалах.
