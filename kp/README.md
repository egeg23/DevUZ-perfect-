# Коммерческие предложения

КП свёрстано, а не набрано в редакторе: правка цены — правка строки, а не
перерисовка макета, и через минуту готов новый PDF. Палитра и гарнитуры
берутся не с нашего сайта — заказчик смотрит на документ, чтобы увидеть свой
будущий сайт, а не нашу студию.

| Файл | Для кого |
| --- | --- |
| `mavera.html` | Исходник. Открывается в браузере, правится текстом. |
| `mavera.pdf` | То, что уходит клиенту в мессенджер. |
| `coffee.html`, `coffee.pdf` | Кофейне без названия: брендинг, SMM, таргет по прайсу маркетинга минус 10%. Менеджер отправляет как есть. |
| `coffee-uz.html`, `coffee-uz.pdf` | То же на узбекском (латиница). |
| `partner-kp.html`, `partner-kp.pdf` | КП для партнёров: услуги и цены, свежие работы, ставки, грейды, контакты. На фирменном бланке. |
| `partner-grades.html`, `partner-grades.pdf` | Грейды партнёров: уровни агентств и блогеров, надбавки (владелец, 12.10.2026). На бланке. |
| `asmo.html`, `asmo.pdf` | Asmo Clinic (asmoclinic.uz): новый сайт клиники, база 1 700 $, со всеми допами 3 000 $, три варианта. Состав и цены — `scripts/protos/asmo/plan.mjs`. На бланке. |
| `inapp.html`, `inapp.pdf` | Турагентство inapp.uz: мобильное приложение, «Минимум» 5 900 $, «Максимум» 7 900 $, допы, наличными минус 10% от цены. Состав и цены — `scripts/protos/inapp/plan.mjs`. На бланке. |
| `sia-dogovor.html`, `sia-dogovor.pdf` | Архитектурное бюро SIA (sia88.ru): договор на сайт 400 000 ₽ и панель 50 000 ₽, аванс 50%, 5 кругов правок на блок, смета приложением. Юрлица не указаны: поля пустые, в подвале бланка только сайт (`data-no-legal`). |
| `managers-bloggers.html`, `managers-bloggers.pdf` | Памятка менеджерам: как привлекать блогеров, бонус менеджера, тексты, возражения. На бланке. Команде — только по слову владельца. |

Документы на бланке (`partner-*`, `managers-*`) подключают `letterhead.css` и
`letterhead.js`: шапка, подвал с реквизитами и номер страницы ставятся на
каждый лист `.sheet` сами — как у `components/docs/letterhead.tsx`.

Клиенту отправляем PDF, а не ссылку: ссылку он не откроет с чужого телефона,
а файл перешлёт руководителю.

## Собрать заново

```
node scripts/kp-pdf.mjs kp/mavera.html kp/mavera.pdf
```

Скрипт меряет каждый лист и возвращает ненулевой код, если тот перерос A4.
Лист, выросший хотя бы на пиксель, в PDF разрывается пополам: вторая половина
уезжает на пустую страницу с обрезанным подвалом, и смета оказывается на
развороте. Поэтому проверка машинная, а не «посмотрел и вроде влезло».

Шрифты лежат в `kp/fonts/` и подключаются из `kp/fonts.css`. Пересобирать их
нужно, только если меняется набор гарнитур:

```
node scripts/kp-fonts.mjs
```

Своя пара гарнитур под клиента — с именем набора, в `kp/fonts-<имя>.css`
(так собраны Lora и Manrope кофейни):

```
node scripts/kp-fonts.mjs coffee "Lora:wght@400;500;600" "Manrope:wght@400;500;600;700"
```

Цены в КП по маркетингу берутся из `content/marketing.ts` (и сверяются с
живой devuz.studio/ru/marketing); как посчитана скидка, записано в
комментарии в начале файла КП. Текст без длинных тире и штампов ИИ, как в
макетах: проверка — `pageProblems` из `lib/proto/plain-text.ts`.

## Как устроена вёрстка

Документ собран листами A4 (`.sheet`), а не сплошным потоком. Так экранная
версия и PDF ломаются по страницам одинаково: то, что видно в браузере, и
есть то, что уйдёт клиенту. Открывающий и закрывающий листы тёмные, рабочие —
на кремовой бумаге: КП печатают в отделе продаж, и пять тёмных страниц там
превращаются в пять листов расхода тонера.

Нумерация страниц в подвалах проставлена руками. Автоматической её делать
нечем: `@page` считает страницы, но достать счётчик в разметку нельзя.
Добавили лист — поправьте `N / 5` во всех подвалах.
