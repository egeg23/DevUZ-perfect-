# Нейтральные фото ниш для «Макета в боте»

Фото ниши — тем, у кого на сайте своих нет (lib/proto/instant). Без людей,
вывесок и чужих брендов; сделаны один раз в Higgsfield (10.11.2026), не
больше 10 на нишу. Фото прошлых клиентов сюда не кладём никогда.

- `stomatologiya/n1-n4.webp` — кабинет, ресепшен, инструменты, коридор.
- `medcentr/n1-n4.webp` — холл, кабинет врача, кабинет УЗИ, вход: вырезаны
  из вертикальных ключевых кадров пролёта медцентра (scene.py), отдельно не
  генерировались.
- `mebel/n1-n5-{1200,900}.webp` — светлая кухня с островом, гардеробная,
  тёмная кухня с подсветкой, цех, образцы фасадов (Higgsfield, 11.11.2026).
- `restoran/n1-n4-{1200,900}.webp` — зал вечером, стол к ужину, блюда на
  столе, мангал (Higgsfield, 11.11.2026).
- `turagentstvo/` — море на закате и направления (`d-<страна>`): свободные
  снимки Unsplash из макета SEM Travel (их собственных фото там нет,
  `scripts/protos/semtravel/SOURCES.md`), 11.11.2026.
- `uchebnyy-centr/n1-n2-{1200,800}.webp` — пустой класс с партами, стол
  ученика с тетрадями (Higgsfield, 11.11.2026). Фото преподавателя Aipply
  не берём.
- `nedvizhimost/` — дома во дворе и башня на закате (`hero`, `hero-m`),
  район с парком (`city`), гостиная, кухня, частный дом (`n1-n3-{900,600}`)
  (Higgsfield, 11.11.2026). Фото Ташкента из макета ShahaR — Wikimedia с
  подписью авторов, не берём.
- `magazin/n1-n4-{900,600}.webp` — коробки и пакет, подарочная коробка, товары для дома, посылка в крафте (Higgsfield, 12.11.2026). Фото банок Greenwell не берём.
- `avtoservis/` — пустой цех с подъёмником (`far-2000`, `far-1100`), машина
  без марки, эмблем и номеров на прозрачном фоне (`car`) и её диски
  (`rim-f`, `rim-r`) для сцены «машина съезжает с подъёмника»; двигатель,
  ходовая на подъёмнике, верстак с инструментом, шиномонтаж
  (`n1-n4-{1200,900}`) (Higgsfield, 12.11.2026). Фото AUTOMECHANIC —
  Wikimedia с подписью авторов и BMW, не берём.
- `logistika/n1-n4-{1200,900}.webp` — ночной грузовой узел, склад со
  стеллажами, контейнерный порт, фура на трассе (Higgsfield, 12.11.2026).
  Кадры сцены залёта Cargo Pro не берём: они из их знака.
- `stroitelstvo/` — гостиная после ремонта (`hero`, `hero-900`), кухня с
  островом, ванная, черновой этап, частный дом, спальня, образцы материалов
  (`n1-n6-{1200,640}`), широкая гостиная-кухня для просмотра с поворотом
  (`pano`) (Higgsfield, Nano Banana, 12.11.2026). Фото Lider Prof не берём.
