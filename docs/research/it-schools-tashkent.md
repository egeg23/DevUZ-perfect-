# IT-школы Ташкента: что на их сайтах

Снято 05.10.2026: голый HTML через curl (то, что получает поиск и превью
мессенджера) и отрендеренный DOM через Chromium. Нужно для прототипов школ и
учебных центров: что у рынка уже есть, а чего нет ни у кого.

## Как устроены сайты

| Школа | Как отдаёт страницу | Что видит поиск |
|---|---|---|
| it-academy.uz | Vite + React, пустая оболочка | 1 506 байт HTML, `<div id="root">` и бандл 578 КБ (162 КБ в gzip). Нет description, OG-картинки, JSON-LD; robots.txt и sitemap.xml отдают ту же оболочку |
| najottalim.uz | Next.js, сервер | title, description, og:image, sitemap; JSON-LD нет; только узбекский |
| proweb.uz | Nuxt, сервер | hreflang ru/uz, самый полный JSON-LD (Organization, LocalBusiness, Course, AggregateRating) |
| astrum.uz | сервер, jQuery | нет description и og:image, sitemap 404, на узбекской странице `lang="en"` |
| tashkent.itstep.org | сервер | JSON-LD Organization; на странице курса зарплата в гривнах — ошибка шаблона |
| mohirdev.uz | Astro | description, og:image, JSON-LD; только узбекский |
| marsit.uz (детская) | Nuxt, сервер | лучшее SEO в выборке: FAQPage, hreflang uz/ru/en |

pdp.uz на момент проверки не работал («Domain has been assigned…»).

## Чего нет ни у кого

1. Редактора, где посетитель сам запускает код.
2. Калькулятора «стоимость курса против зарплаты junior».
3. Ссылок в Telegram с уже написанным текстом (`t.me/…?text=`).
4. Разметки Course с ценой и CourseInstance.
5. Современного CSS-движения: scroll-driven animations, View Transitions.
6. Квиза, который отвечает сразу, без телефона.

## Мировые ориентиры

- react.dev — живые примеры кода рядом с превью.
- brilliant.org — интерактив вместо картинки.
- scroll-driven-animations.style — программа курса, которая раскрывается по
  прокрутке без скрипта.

## Как это легло в прототип

Прототип учебного центра собирается из нескольких страниц под одной ссылкой
(`/proto/<токен>/kurs/python`, lib/proto/pages): у каждой страницы курса свой
title, description, OG и разметка Course — так владелец видит не картинку
главной, а то, как сайт будет выглядеть для поиска.
