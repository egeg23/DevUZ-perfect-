# Cosmo World (cosmoworld.uz): разведка под премиум-макет

Задача владельца DevUz, 28.10.2026: «Референс можно взять на основе их
текущего сайта, со скролл пролётом и тд. Можно через mcp сделать видео,
потом разбить на кадры и сделать скролл анимацию. Покажи 2-3 референса чтобы
я утвердил, и анимацию пролёта допилим, но сначала картинками референсы».

Рецепт — `.claude/skills/proto-master/premium.md` (эталон SamAuto). Факты для
макета — `scripts/protos/cosmoworld/data.mjs`.

## Что у них слабо (для разговора с клиентом)

- Одна страница: бренд, каталог и партнёрство не находятся поиском, у
  бренда нет своей страницы.
- Каталог — только PDF на Яндексе: с телефона это скачать 10-30 МБ, чтобы
  найти одну позицию.
- Карта покрытия — картинка: не видно, кто их представитель в области.
- «Где купить» — логотипы без адресов.
- Нет узбекского языка.
- Форма сотрудничества одна на всех: магазин, сеть и производитель пишут
  в одно поле.
- На сайте «© Cosmo World, 2025» по-русски и «2024» в английской версии.

## Сцена: раскадровка по вариантам

Референсы нарисованы в родительской сессии (nano_banana_2_1, 2K, 16:9),
стиль — скрин рекламы Revolut, который дал владелец: почти чёрно-белое
ночное небо, объёмные облака, полная луна, в центре парит стекло.

1. **«Луна над облаками»** (job `568afd03…`): стеклянный подиум с их
   товарами над морем облаков.
   Пролёт: облака расступаются → камера ныряет под подиум, товары
   разлетаются в кольцо брендов → сквозь облака вниз к ночному складу
   (стеллажи светятся голубым) → выше, Узбекистан с орбиты, дуги доставок
   → сайт.
2. **«Орбита»** (job `26c20f8e…`): ночная Земля с орбиты, голубые дуги из
   Ташкента по стране и в Бишкек.
   Пролёт: орбита → камера падает к Ташкенту → склад сверху → товары на
   стеклянной полке → сайт. Ближе всего к их нынешнему первому экрану.
3. **«Планета с кольцом из товаров»** (job `f821ccfc…`): стеклянная
   тёмно-синяя планета, кольцо из сотен их флаконов.
   Пролёт: камера влетает в кольцо, флаконы проносятся мимо и
   выстраиваются в полку брендов → внутрь планеты, это склад → наружу к
   карте покрытия → сайт.

Порядок по `premium.md` §3: ключевые кадры 4K от одобренного кадра (16:9 и
9:16 отдельно) → раскадровка картинками владельцу → после «да» переходы
Kling 3.0 4K, 6-10 с, без звука → WebP 1920/828, телефону видео с каждым
кадром ключевым → шифр `seal.py`, ключ `SCENE_KEY_COSMOWORLD`.

Бюджет MCP — не больше 25% от общего объёма.
