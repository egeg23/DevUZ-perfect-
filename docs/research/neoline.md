# Neoline (neoline.uz): разведка для макета

Задание владельца DevUz, 28-29.10.2026. Клиент — официальный магазин Neoline в
Узбекистане (ООО «Neoshop»): радар-детекторы и гибриды X-COP, видеорегистраторы,
автоакустика Ultera, аксессуары. Сайт на WordPress + WooCommerce, языки uz и ru.

Правило задания: ни Higgsfield, ни Firecrawl, ни других MCP для этого клиента;
ни ProxyAPI, ни нашего прокси к модели. Разведка — их открытый Store API
(`/wp-json/wc/store/v1/products`), их страницы и встроенный поиск сессии.

## Приёмы (awwwards и 21st.dev)

Сайты страниц-товаров с наград awwwards (раздел Sites of the Day, страницы
гаджетов и автомобилей) держатся на трёх вещах: сцена по прокрутке, где товар
«работает», крупный товар на тёмном поле со светом по краю, и детали по
нажатию. Конкретные ролики оттуда мы не копируем, механики собраны своим кодом:

- залёт камеры в бренд — CHECHFARM (PR #599), буквы Unbounded, three.js;
- «Радар в деле» — липкая сцена, прокрутка только читается;
- стеклянные папки, Text Reveal, Scroll Velocity — по Cosmo World;
- Spotlight Card, Shimmer Button, Animated Tabs — по мотивам 21st.dev
  (подробно — `scripts/protos/neoline/21ST.md`);
- стенд с ракурсами пальцем — по SamAuto, но из их собственных фото;
- магазин, панель и заказ «сайт → панель → сайт» — эталон Greenwell.
