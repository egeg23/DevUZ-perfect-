# Площадки для статей: набор регистрации

Владелец, 09.11.2026: «Я хочу минимизировать ручной труд на статьях… Я
прям правда не смогу на 25 ресурсов каждый день что-то выкладывать». На
план — «Делаем, Postiz тоже подключи».

Регистрацию делает человек, один раз, примерно за два часа. Это может быть
менеджер. Роботом регистрироваться нельзя. Почти везде есть капча, код по
SMS и подтверждение почты, и робота за их обход банят вместе с именем
студии. После регистрации публикует код: раз в неделю, своим текстом на
каждую площадку, без человека (раздел «Статьи на площадках» в панели).

**Пароли и коды в чат, в задачи и в этот файл не пишем.** Репозиторий
открытый. Логин и пароль от площадки остаются у того, кто регистрировал, в
его менеджере паролей. В панель вставляется только ключ API, и только в
поле «Ключ API Postiz».

## Что подготовить до начала

- **Почта студии** для всех площадок. Удобнее одна общая, например
  `press@devuz.studio`, а не личная почта сотрудника, чтобы аккаунты не
  ушли вместе с человеком.
- **Телефон для SMS.** Нужен ВКонтакте и Telegram. Лучше рабочий номер
  студии.
- **Картинки** из репозитория:
  - аватар: `public/brand/telegram-avatar-1024.png` (квадрат, 1024 px);
  - знак без фона: `public/brand/logo-square-1200-alpha.png`;
  - обложка: `public/og-ru.png` (1200×630).
- **Тексты профиля** — ниже, копировать как есть.

## 1. Публикуется само: подключить один раз

| Площадка | Что сделать | Куда потом |
|---|---|---|
| Telegraph | Ничего. Аккаунт студии код заводит сам с первой статьёй. | — |
| Postiz | Зарегистрироваться на [postiz.com](https://postiz.com) почтой студии. Выбрать тариф на их сайте. | Settings → Developers → Public API → скопировать ключ → панель, «Статьи на площадках» → «Ключ API Postiz» → «Сохранить и проверить» |
| ВКонтакте | Завести сообщество студии ([vk.com/groups](https://vk.com/groups) → «Создать сообщество», тип «Бизнес»), поставить аватар, обложку и описание. В Postiz: «Add Channel» → VK → войти и выбрать сообщество. | В панели после «Сохранить и проверить» появится строка «публикуются сами: ВКонтакте» |
| Telegram-канал | Создать канал студии в Telegram (публичный, адрес вроде `@devuz_studio`), аватар и описание. В Postiz: «Add Channel» → Telegram и шаги на экране: добавить бота Postiz в канал администратором. | Та же строка: «публикуются сами: Telegram-канал» |

После «Сохранить и проверить» панель покажет, какие каналы видит Postiz.
Новая площадка получает статьи со следующей недели.

## 2. Руками: черновик готовит код, публикует человек

Каждую неделю в «Статьях на площадках» по черновику на площадку. Нужно
нажать «Скопировать», вставить, опубликовать и вставить ссылку на статью.
Это минуты 3–5 на площадку.

| Площадка | Регистрация | Читатель |
|---|---|---|
| [vc.ru](https://vc.ru) | Вход почтой или через Яндекс, потом «Создать блог» на студию | предприниматели и маркетологи, Россия и СНГ |
| [Дзен](https://dzen.ru) | Аккаунт уже есть (вход Яндексом) | владельцы малого бизнеса, Россия |
| [Tenchat](https://tenchat.ru) | Вход по телефону, профиль компании | деловая соцсеть, Россия |

## 3. Следующий шаг: английские площадки для США

Postiz их тоже публикует сам, но статьи там нужны по-английски, со своими
темами. Это отдельная доработка, когда владелец скажет «начинаем». Аккаунты
можно завести заранее, той же почтой студии:

- [LinkedIn](https://www.linkedin.com/company/setup/new/): страница компании;
- [Dev.to](https://dev.to/enter): блог разработчиков;
- [Hashnode](https://hashnode.com/onboard): свой блог, адрес вроде `devuz.hashnode.dev`;
- [Medium](https://medium.com): Postiz подключает его по ключу, а новых
  ключей Medium с 2025 года не выдаёт, поэтому там, скорее всего, руками;
- [Pinterest](https://www.pinterest.com/business/create/): бизнес-аккаунт,
  пины с кадрами наших работ;
- каталоги студий [Clutch](https://clutch.co/get-listed),
  [GoodFirms](https://www.goodfirms.co/), [DesignRush](https://www.designrush.com/agency/register):
  профиль один раз и отзывы клиентов, статей там нет.

## Что не делаем

- Не регистрируем и не публикуем роботом в браузере: это против правил
  площадок и кончается баном.
- Не пишем один и тот же текст на все площадки: поисковики считают это
  спамом. Код пишет свою версию под каждую.
- Не публикуем каждый день: одна статья в неделю на площадку.
