# ИИ-сотрудник «Блогеры»

Задача владельца, 11.10.2026: «Нам нужен агент, который бы общался в
инстаграм, писал блоггерам по партнерской программе, сам бы их собирал,
просил, оценивал аудиторию. В ИИ работниках бы добавил это и реализовать
внутри у нас в разделе «ИИ работники», чтобы это был не только внешний
сервис, но и наш внутренний».

Порядок: сначала наш внутренний агент (вкладка «Блогеры» в
`/admin/ai-staff`), потом та же роль в сервисе по подписке.

## Как агент пишет — без риска бана

Официальный API Instagram не даёт писать первым: только отвечать в течение
24 часов после сообщения человека. Входить в Instagram-аккаунт студии
посторонней программой (как скаут в Telegram) не делаем: за это Instagram
блокирует аккаунт. Поэтому:

| Что есть у блогера | Что делает агент |
|---|---|
| Telegram в шапке профиля или на его сайте | Первым уходит только «Здравствуйте» с рабочего аккаунта студии, по правилам касаний: предел в час на аккаунт, окно отправки, проверка бана (`lib/admin/hello-first.ts`). Своя квота «Telegram в день», по умолчанию 3, — норму в 20 касаний компаний не трогает |
| Почта | Готовит письмо; менеджер нажимает «Скопировать и открыть почту», отправляет и «Отправил» |
| Только Instagram | Готовит текст; менеджер нажимает «Скопировать и открыть Direct» (`ig.me/m/<ник>`), отправляет с телефона с аккаунта студии и «Отправил» |
| Блогер ответил в Direct аккаунту студии | Переписку ведёт агент через официальный API (окно 24 часа, `lib/ai-staff/instagram.ts`), просит скриншоты статистики и разбирает их моделью с картинками |

Текст первого сообщения — шаблон кода (`pitchText`, `lib/bloggers/rules.ts`),
не модель: проценты и минимальная выплата берутся из
`lib/partners/rules.ts` (`programTerms`), свои цифры агент не придумывает.
Это держит тест `tests/bloggers.test.ts`.

ИИ говорит, что он ИИ (`legal.md`): в переписке, которую ведёт агент, первое
его сообщение называет себя ИИ-помощником студии. Первое сообщение, которое
отправляет человек со своего телефона, пишет человек.

## Где берёт блогеров и как оценивает

- **Поиск** — Firecrawl (`firecrawlSearch`) по запросам из настроек, по кругу
  (`nextQuery`). Из выдачи — профили Instagram с числом подписчиков из
  описания («12K Followers…») и ники из статей-подборок (`candidatesFrom`).
  Кредиты — из общего дневного лимита (`lib/firecrawl.ts`, `dailyAllowance`),
  но не больше своей доли «Кредитов поиска в день» (по умолчанию 2):
  поиск компаний для касаний из-за блогеров не встаёт. Расход пишется в
  `firecrawl_usage` с `kind = 'bloggers'`.
- **Цифры профиля** — Instagram Graph API, Business Discovery
  (`lib/bloggers/discovery.ts`): подписчики, шапка, сайт, лайки и
  комментарии последних 12 постов → вовлечённость и частота постов. Только
  для профессиональных аккаунтов (бизнес или автор). Без ключей — цифры
  только из выдачи поиска.
- **Контакты** — Telegram и почта из шапки профиля и с его сайта (одна
  страница своим обходом, без Firecrawl; `contactsFromBio`).
- **Темы, язык, город, подходит ли аудитория** — недорогая модель
  (`BLOGGER_MODEL`, по умолчанию Haiku), `lib/bloggers/judge.ts`.
- **Балл 0–100** — код (`scoreBlogger`): размер 20, вовлечённость 30,
  активность 15, Узбекистан 15, тематика 20. Ниже проходного (55) или вне
  рамок по подписчикам — «Отсеяны».

Проход агента — в свипе (`app/api/reminders/sweep`, `bloggerPass`), с 9:00
до 20:00 по Ташкенту: до трёх оценок за проход, поиск — когда оценивать
некого. Агент выключен — один запрос к настройкам.

## Данные (миграция `0103_bloggers`)

| Таблица | Что хранит |
|---|---|
| `bloggers` | Ник, цифры профиля, темы, контакты, балл, статус, канал, текст первого сообщения, переписка, аудитория по скриншотам, партнёр |
| `blogger_settings` | Включён ли агент, квоты на день, рамки по подписчикам, проходной балл, запросы поиска |

Статусы: `found` → `ready` / `skipped` → `queued` (Telegram) → `contacted` →
`replied` → `stats` → `agreed` → `partner`, или `declined` / `unreachable`.

## Партнёр

Блогер согласен — «Сделать партнёром»: `createPartner` в
`lib/partners/store.ts` заводит партнёра и основную ссылку
`partner_links`. Telegram id блогера неизвестен — партнёр без него.

## Доступ

Раздел «ИИ-сотрудники» видят владелец и руководитель. Вкладка «Блогеры» —
обоим; клиенты сервиса по подписке, деньги и подписки — только владельцу
(страница `/admin/ai-staff` уводит руководителя на «Блогеры», действия
`app/admin/ai-staff/actions.ts` — `requireAdmin`).

## Что нужно от владельца

1. **Instagram-аккаунт студии — профессиональный и привязан к странице
   Facebook.** В приложении Instagram: Настройки → Тип аккаунта →
   «Перейти на профессиональный» (Бизнес); затем Meta Business Suite
   (business.facebook.com) → Настройки → Аккаунты Instagram → привязать к
   странице Facebook студии.
2. **Приложение Meta с Business Discovery.** developers.facebook.com → Мои
   приложения → то же приложение, что для Instagram клиентов сервиса, или
   новое типа «Бизнес» → продукт «Instagram» с входом через Facebook → права
   `instagram_basic`, `pages_show_list`, `pages_read_engagement`.
   В Graph API Explorer получить долгий токен страницы и id Instagram-аккаунта
   студии и положить в хранилище секретов: `BLOGGERS_FB_TOKEN`,
   `BLOGGERS_IG_USER_ID`. Без них агент оценивает только по выдаче поиска.
3. **Direct студии для ответов агента** — тот же вход через Instagram, что у
   клиентов сервиса (`AI_STAFF_IG_APP_ID`, `AI_STAFF_IG_APP_SECRET`,
   `AI_STAFF_IG_VERIFY_TOKEN`, разрешение
   `instagram_business_manage_messages` после проверки бизнеса в Meta), и
   подключить аккаунт студии кнопкой во вкладке «Блогеры».
4. **Firecrawl** — ключ уже есть (`FIRECRAWL_API_KEY`); доля блогеров в день
   меняется в «Настройки агента».
