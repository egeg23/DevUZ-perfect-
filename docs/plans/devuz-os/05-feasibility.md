# 5. Реализуемость: что сделаем вдвоём, где риски

Команда: владелец и сессии Claude (Opus и Fable). Инженеров нет. Это
главное ограничение.

## Что Claude делает хорошо, а что упирается в руки

| Работа | Кто | Оценка |
|---|---|---|
| Рецепты образа mkosi, юниты systemd, quadlet, sysupdate, repart | Claude | ✓ текст, проверяется в QEMU и в Actions |
| Конвейер сборки и подписи в GitHub Actions | Claude | ✓ как уже есть для сайта и Strapi |
| Приложения «Офиса» на Node, перенос модулей студии | Claude | ✓ основной объём, язык и подход знакомы |
| «Ядро» (шлюз моделей) | Claude | ✓ есть основа `lib/llm/` |
| Тесты: загрузка, подпись, TPM, откат, копии — в QEMU + swtpm | Claude | ✓ без железа |
| Замеры моделей, качество ru/uz | Claude + облачная машина с GPU | ✓ для NVIDIA; для AMD — только на образце |
| Первое включение железа, прошивка, Secure Boot на настоящей плате | **владелец руками**, Claude по удалённому доступу | ⚠ главный риск по времени |
| Голос: задержка звонка, эхо спикерфона | владелец + Claude | ⚠ требует живых проб |
| Обучение слова «Джарвис», запись узбекского голоса | владелец (диктор, запись), Claude (обучение) | ⚠ нужен человек с голосом и студия |
| Завод: прошивка с нашими ключами, проверка партии | владелец на месте | ⚠ зависит от завода |
| Юрист (GPLv3, лицензии, ввоз шифрования, звонки) | внешний | ✗ сами не закрываем |

Вывод: **программная часть реальна для двоих**, если держать первую
версию узкой (см. «первая версия» в [03-functions.md](03-functions.md)).
Медленнее всего пойдёт всё, что требует рук и железа.

## Риски

### Высокие

1. **ROCm на Strix Halo (gfx1151).** Поддержка в ROCm 7.x по источникам
   спорная, официальные колёса PyTorch без gfx1151 **[не проверено]**.
   Чат и рассуждение — на Vulkan (llama.cpp), это работает у сообщества.
   Картинки, видео, CosyVoice, Whisper на GPU на AMD — **под вопросом**.
   Решение: на Лайт и Про обещаем только чат, документы, голос (Whisper
   на процессоре тоже успевает для голосовых), медиа — на Джарвисе.
2. **Задержка голосового звонка.** Чтобы робот звучал как человек, ответ
   нужен за ~1 с: Whisper + модель + синтез. На Про с gpt-oss-120b при
   46–55 ток/с первые слова — успеваем, если начинать синтез по
   первым словам; на Лайт — нет. **[Не проверено, замер на образце.]**
3. **Узбекский язык.** Качество Qwen на узбекском проверяем сами;
   узбекского синтеза голоса с коммерческой лицензией нет — свой голос
   (запись диктора 5–20 часов, обучение Piper/VITS). Без этого звонки —
   только по-русски.
4. **Ключи подписи.** Потеря = нельзя выпускать обновления на проданные
   коробки; утечка = кто угодно подпишет свою систему. Аппаратный ключ,
   две копии, процедура.
5. **Поддержка на годы.** Своя ОС — это обязательство: обновления
   безопасности Debian каждую неделю, новое ядро, новые драйверы NVIDIA,
   переезд на Debian 14. Конвейер должен пересобирать и проверять сам;
   иначе через полгода мы утонем.

### Средние

6. **Драйвер NVIDIA и ядро.** Новое ядро ломает сборку модуля — конвейер
   ловит до выпуска. Ошибки GSP (Xid 119) на RTX PRO 6000 под нагрузкой
   встречались в ранних драйверах **[проверено: форум NVIDIA, драйвер
   575]** — выбирать проверенную ветку, прогон 24 часа под нагрузкой.
7. **Option ROM и Secure Boot на Джарвисе** — проверить, что карта
   стартует с нашими ключами + Microsoft UEFI CA.
8. **fTPM AMD** — сброс при обновлении прошивки, замена платы = новый TPM.
   Ключ восстановления обязателен, мастер его проверяет.
9. **Лицензии.** Каждая модель и программа — до включения в коробку;
   текущий текст лицензии драйвера NVIDIA; GPLv3 (раздел 4); Piper
   (новая ветка — GPL-3); pyannote; Tabby; модели музыки и 3D не выбраны.
10. **Размер образа в GitHub Actions.** У обычных раннеров ~14 ГБ места
    (после чистки больше), CUDA — гигабайты. Решение: NVIDIA — отдельное
    расширение, при нехватке — большие раннеры или свой раннер **на
    отдельной машине, не на боевом сервере** (правило CLAUDE.md).
11. **Ширина продукта.** 45 сценариев и 14 направлений — вдвоём это
    годы. Держим первую волну узкой, остальное — обновлениями и магазином.

### Внешние (не техника)

12. **Ввоз шифрования.** В Узбекистане и России ввоз средств шифрования
    регулируется (нотификации, разрешения). Коробка с LUKS и WireGuard —
    под вопросом классификации **[не проверено — брокер и юрист]**.
13. **Сертификация.** Соответствие для ИТ-оборудования (O‘zstandart),
    Wi-Fi — радиочастоты; для госсектора — свои требования к защите
    информации. На пилот не нужно, к продаже — нужно **[не проверено]**.
14. **Звонки.** Запись разговоров — уведомление собеседника; подключение
    SIP — договор с оператором; холодный обзвон роботом — не делаем.
15. **Имя «Джарвис»** — товарный знак Marvel/Disney для персонажа; как
    название модели коробки и слово пробуждения — **проверить у юриста**
    до печати на коробке ([07-name.md](07-name.md)).

## Что упирается в железо

- Скорость моделей на Strix Halo, Vulkan против ROCm, `ttm.pages_limit`.
- Температура и шум в своём корпусе (особенно Джарвис ~20 л).
- Secure Boot и прошивка конкретной платы (ключи в «заводских
  настройках», пароль, отключение загрузки с USB).
- fTPM или отдельный TPM-чип.
- Спикерфон и эхо в настоящей комнате.
- Option ROM RTX PRO 6000.

Всё остальное — до железа (см. [06-roadmap.md](06-roadmap.md)).

## Честный итог

- **Сделать можно**: своя система на Debian с запертой загрузкой, A/B и
  TPM — посильна, потому что почти всё готово в systemd и проверяется без
  железа. Приложения — продолжение того, что у студии уже работает.
- **Сложно**: голосовые звонки с низкой задержкой, узбекский голос, медиа
  на AMD, поддержка системы годами.
- **Не сами**: юрист, завод, сертификация, ввоз.
- **Срок** до первой коробки, на которой студия живёт сама, — ~4 месяца
  (раздел 6); до партии для клиентов — реально к лету 2027, что сходится с
  запуском продаж в октябре 2027.
