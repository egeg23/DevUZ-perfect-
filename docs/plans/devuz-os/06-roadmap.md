# 6. Порядок работ по неделям

Каждая неделя заканчивается **проверяемым результатом**: что можно
показать или что проходит тест. Неделя 1 — первая неделя после слова
владельца «начинаем».

Где живёт код ОС — решение владельца (см. README): отдельный репозиторий
`egeg23/devuz-os` (рецепты образа и приложения коробки), ключи подписи — не
в нём.

## Часть А. До железа (недели 1–8)

Всё — в QEMU с OVMF (UEFI с Secure Boot) и swtpm (программный TPM), сборка
и тесты — в GitHub Actions. Для NVIDIA — облачная машина с GPU по часам.
AMD Strix Halo в облаке не бывает: всё про AMD — в части Б.

| Неделя | Что делаем | Проверяемый результат |
|---|---|---|
| 1 | Репозиторий, mkosi-рецепт Debian 13 + ядро 6.18 из backports, systemd-boot, UKI | Образ собирается в Actions и грузится в QEMU до экрана «Состояние» — тест в Actions зелёный |
| 2 | `/usr` на erofs + dm-verity, разметка A/B (`systemd-repart`), `systemd-sysupdate` с тестового сервера, счёт загрузок | Тест: обновление A→B проходит; «битое» обновление после 3 попыток откатывается на A само |
| 3 | Тестовые ключи Secure Boot в OVMF, подпись UKI и verity, LUKS2 + TPM (swtpm) по подписанной политике PCR 7+11, ключ восстановления | Тесты: подменённый UKI не грузится; диск открывается сам; после обновления — тоже; с чужим загрузчиком — нет, ключ восстановления открывает |
| 4 | Службы: Podman + quadlet, подпись контейнеров (policy.json), PostgreSQL, Caddy, сторож на systemd, Tailscale-клиент + свой Headscale (тестовый), кнопка поддержки | Тест: неподписанный контейнер не стартует; убитая служба поднимается; кнопка выключает канал |
| 5 | «Ядро»: шлюз моделей (из `lib/llm/`), очередь, маршрут по задаче. Облачная машина с NVIDIA: vLLM + gpt-oss-120b, faster-whisper, bge-m3 + Qdrant. Сборка расширения NVIDIA (открытые модули, подпись) | Наш код студии (`anthropic(site)`) отвечает через «Ядро» на облачной машине; замеры ток/с записаны |
| 6 | «Офис» v0: единое окно (перенос `syanie/app`), ИИ-сотрудник (`lib/ai-staff/engine.ts`) на локальной модели, чат по документам | Демо: сообщение в тестовый Telegram-бот → ответ локальной модели → карточка в «Офисе» |
| 7 | Сравнение моделей на русском и узбекском («Сравнение Claude и Qwen», набор для коробки): gpt-oss-120b, Qwen3.5-122B, Qwen3.6-35B. Копии Restic, «Скачать всё», проверка копий. Манифесты и подпись моделей | Таблица качества по моделям → выбор главной модели и `chat-uz`; тест: копия восстанавливается на чистой виртуалке |
| 8 | Мастер первой настройки, «Состояние», обновления по каналам. Заводская флешка: запись ключей, установка, опись деталей, отчёт | Тест в QEMU «из коробки»: от включения до первого ответа ИИ < 30 минут, без терминала |

**Итог части А**: система, которая ставится, обновляется, откатывается,
шифруется и отвечает локальной моделью, — проверено без коробки.
Параллельно владелец: заказ образца «Про», юрист (GPLv3, ввоз, звонки,
имя), выбор имени.

## Часть Г. Завод в Китае: пилотная партия ~10 штук

**До поездки (2–3 недели):**

- Требования к заводу письменно: наши ключи Secure Boot в «заводских
  настройках» прошивки, логотип в прошивке, пароль на прошивку,
  выключенная загрузка с USB, TPM включён, опись серийников.
- Заводской комплект: флешка установки (подписанная), скрипт прогона
  (нагрузка 12 ч, температура, память, диск, сеть, звук), печать наклейки
  с номером и QR, лист приёмки.
- Ключи: боевые ключи Secure Boot — на аппаратном ключе владельца;
  на завод едет **только открытая часть** для записи в прошивку и
  подписанные образы. Закрытые ключи на завод не везём.

**На заводе (≈1 неделя):**

| День | Что | Результат |
|---|---|---|
| 1 | Прошивка с нашими ключами от завода: проверка на 1 штуке | Наша система грузится, «сброс настроек» возвращает наши ключи |
| 2 | Установка на все ~10 (пара каждой модели), опись деталей | 10 записей в журнале: серийники, версии |
| 3–4 | Прогон 12–24 часа, температура в своём корпусе, доводка защиты: USB, пароль, TPM | Лист приёмки по каждой: зелёная или причина |
| 5 | Повтор для забракованных, упаковка, комплект (ИБП, резервный диск, спикерфон) | Партия к отправке, отчёт владельца |

**После партии**: 10 коробок — студия, 2–3 дружественных клиента бесплатно
или со скидкой на 2–3 месяца, обратная связь → первая версия к запуску
продаж (октябрь 2027 по роадмапу `/box`).
