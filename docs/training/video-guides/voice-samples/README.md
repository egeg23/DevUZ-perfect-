# Образцы голоса для учебных видео

Здесь шесть записей одного и того же абзаца, озвученного разными бесплатными
программами синтеза речи. Цель — выбрать голос для внутреннего обучающего
видеокурса студии и проверить, можно ли нам законно пользоваться этим голосом.

Текст образца:

> Представьте, что сайт — это витрина магазина на оживлённой улице. Человек
> идёт мимо, смотрит секунду-две и решает: зайти или пройти дальше. Если
> витрина пыльная, а дверь не открывается, он уйдёт к соседу. Наша работа —
> сделать так, чтобы человек зашёл и оставил заявку. Например, клиент получает
> бесплатный макет за двенадцать часов и видит свой будущий сайт своими глазами.

Всё делалось 13.10.2026 на обычном облачном компьютере без видеокарты
(4 ядра процессора). Все файлы приведены к одной громкости, mp3, 128 кбит/с, моно.

## Как проверяли

- **Разборчивость.** Каждую запись распознавала обратно в текст программа
  Whisper и сравнивала с оригиналом. Ошибки: «12» вместо «двенадцать» не в счёт
  (так распознаватель пишет числа), фраза «Редактор субтитров…» в конце не в счёт
  (распознаватель её выдумывает на тишине).
- **Естественность.** Оценка программы UTMOS по шкале 1–5: чем выше, тем больше
  похоже на живого человека. Это грубая подсказка, а не замена прослушиванию:
  программа учена на английской речи и акцент не слышит.
- **Скорость.** Сколько секунд компьютер думал над записью и во сколько раз это
  быстрее или медленнее самой записи.

## Что с лицензиями, по каждой программе

**Silero** (https://github.com/snakers4/silero-models). Основные русские голоса
(aidar, baya, kseniya, xenia, eugene) выложены под лицензией
CC BY-NC-SA 4.0 — это «только некоммерческое использование». Файл лицензии:
https://github.com/snakers4/silero-models/blob/master/LICENSE, в README:
«All of the models are published under the main repo license (i.e. CC-NC-BY)
except for the base cis-tts models, which are under MIT». Обучение своих
сотрудников в компании — это использование в работе компании, то есть
коммерческое. **Вывод: без покупки лицензии у Silero — нельзя.**
Исключение — модель `v5_cis_base` / `v5_cis_base_nostress`: она под MIT
(https://github.com/snakers4/silero-models/blob/master/LICENSE_CIS), её голоса с
приставкой `ru_` говорят по-русски. **Можно**, но голоса у неё — дикторы других
языков СНГ, по-русски звучат хуже основных.

**Piper** (https://github.com/OHF-Voice/piper1-gpl, программа под GPL-3.0; на
сам звук это не влияет). У каждого голоса своя лицензия
(https://huggingface.co/rhasspy/piper-voices/tree/main/ru/ru_RU):
- ruslan — данные под CC BY-NC-SA 4.0: **нельзя**;
- irina — лицензия данных «Unknown»: **нельзя полагаться**;
- denis и dmitri — данные CC0 (свободно), но все русские голоса Piper
  дообучены из английского голоса lessac, а его данные выданы только «для
  исследований» (Research Licence Agreement,
  https://www.cstr.ed.ac.uk/projects/blizzard/2013/lessac_blizzard2013/license.html).
  **Серая зона**: многие так пользуются, но чистым это не назовёшь. К тому же
  по звуку это самый слабый вариант.

**Vosk TTS** (https://github.com/alphacep/vosk-tts). Программа — Apache 2.0.
Модель `vosk-model-tts-ru-0.9-multi` в своём описании прямо пишет
«License: Apache 2.0» (файл README.md внутри архива модели,
https://alphacephei.com/vosk/models/vosk-model-tts-ru-0.9-multi.zip). Apache 2.0
разрешает коммерческое использование. **Можно.** Оговорка: на каких записях
учили голоса, авторы не раскрывают — это общий риск почти всех открытых
моделей, но формально разрешение дано.

**Qwen3-TTS** (https://github.com/QwenLM/Qwen3-TTS, модель
https://huggingface.co/Qwen/Qwen3-TTS-12Hz-0.6B-CustomVoice). И программа, и
модель — Apache 2.0. **Можно.** Минусы — медленно на нашем компьютере (10 минут
курса ≈ 40 минут ожидания) и нет голоса с родным русским.

**Что не пробовали и почему**
- F5-TTS и русские дообучения (Misha24-10/F5-TTS_RUSSIAN — CC BY-NC 4.0;
  ESpeech — заявлен Apache 2.0, но сделан из базы F5, которая CC BY-NC из-за
  набора Emilia, и учился на записях вебинаров с неясными правами). Кроме того,
  F5 только копирует чужой голос по образцу — нужна запись живого человека и
  его согласие. **Нельзя / серая зона**, поэтому не ставили.
- XTTS v2 (Coqui) — Coqui Public Model License: «allows only non-commercial use
  of a machine learning model and its outputs». **Нельзя.**

## Что выбрать

**Рекомендуем Vosk TTS (модель 0.9-multi), голоса 3 (мужской) и 0 (женский).**
Разрешение на коммерческое использование есть (Apache 2.0), русский родной,
ударения расставляет сам, текст распознаётся без единой ошибки, по
естественности — лучший из «родных русских» голосов, работает быстрее записи на
обычном процессоре. Запасной вариант — Qwen3-TTS (Serena), если на слух он
понравится больше и не слышно акцента: лицензия тоже чистая, но он в 15 раз
медленнее.

Перед окончательным выбором — **послушайте файлы 04, 05 и 06 сами**: машинная
оценка не слышит акцент и «настроение» голоса.

Советы к текстам: числа писать словами; вместо «секунду-две» лучше «секунду или
две» — через дефис некоторые голоса проглатывают слово; спорное ударение в Vosk
можно поставить знаком `+` перед ударной гласной (`з+амок`).

## Как запустить Vosk TTS (для следующего этапа)

```bash
S=/tmp/claude-0/-home-user-DevUZ-perfect-/0e9c36de-2589-53b2-8179-a18958c7d00c/scratchpad/tts
cd $S
uv venv --python 3.12 vosk
uv pip install --python vosk/bin/python vosk-tts          # версия 0.3.61
mkdir -p vosk-models && cd vosk-models
curl -L -o m.zip https://alphacephei.com/vosk/models/vosk-model-tts-ru-0.9-multi.zip
unzip m.zip && cd ..
```

```python
# vosk/bin/python synth.py
from vosk_tts import Model, Synth
model = Model(model_path="vosk-models/vosk-model-tts-ru-0.9-multi")  # ~80 с при первом запуске
synth = Synth(model)
synth.synth(open("text.txt").read(), "out.wav", speaker_id=3)  # 3 — мужской, 0 — женский (всего 0–4)
```

```bash
# в mp3 той же громкости, что образцы
ffmpeg -i out.wav -af "loudnorm=I=-16:TP=-1.5:LRA=11" -ar 44100 -ac 1 -c:a libmp3lame -b:a 128k out.mp3
```
