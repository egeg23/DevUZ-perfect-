# Главная «Самарканд» — выбор владельца, 09.11.2026

Владелец, на PDF «три новые палитры»: «Самарканд — красиво. Запиши,
сегодня ночью сядем делать». Синий (варианты 08.11) — «не нравится мне
палитра».

- `index.html` — макет двух кадров 1440×900 (первый экран и «Продукты
  студии»), картинки берутся из `public/`. Открыть: из корня репозитория
  `python3 -m http.server` → `/docs/design/home-samarkand/`.
- `f1.webp`, `f2.webp` — как это выглядело в PDF.
- Раскладка — «Витрина» (заголовок по центру, наши настоящие сайты и
  телефоны в перспективе по бокам). Палитра ставится и на «Горизонт» и
  «Вызов», если владелец захочет другую раскладку — спросить в начале.

## Палитра

| Токен | Цвет | Где |
|---|---|---|
| `--bg0` | `#03100f` | низ кадра 2, самый тёмный |
| `--bg1` | `#06272a` | середина градиента |
| `--bg2` | `#0b5354` | низ первого экрана, переходит в `#13807c` |
| `--acc` | `#3fd6c8` | бирюза: точка «AI офис», пузырь ответа, градиент слова |
| `--gold` | `#e9c77f` | золото: кнопка, метки «Планируется к запуску», числа |
| `--ink` | `#effaf6` | текст |
| `--soft` | `#bcd8d2` | второй текст |
| `--muted` | `#8db3ac` | подписи |

Свечение снизу — бирюза, узор гирих за заголовком — 9% прозрачности,
гаснет к краям маской. Шрифты — как у «Стекла»: Prata для заголовков,
Onest для текста.

## Что сделать при переводе на сайт

1. Палитру — в `glass.module.css` (или новый модуль), не трогая данные и
   тексты `content/home-copy.ts`: блоки «Стекла» остаются, меняется вид.
2. Шесть языков, телефон 390 и планшет 768, без прокрутки вбок.
3. Картинки целиком (правило «Стекла»): не резать, дорисовать и гасить.
4. Движение — `transform`/`opacity`, при reduced-motion стоит.
5. Снимки — `docs/screens/home-samarkand/`, `tests/home-glass.test.ts`
   зелёный, карта сайта после выкатки.
