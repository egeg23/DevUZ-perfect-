# Фильм о студии на главной

Файлы на сайте: `public/film/devuz-studio.mp4` (1280×536, 2.39:1, без звука,
17,7 с) и обложка `public/film/devuz-studio.webp` — последний кадр с горящей
надписью. Показ — `components/sections/studio-film.tsx`, под числами штата.

## Из чего собран (Higgsfield, 18.10.2026)

| Кадр | Что | Модель |
| --- | --- | --- |
| s1 | общий план офиса: 40+ разработчиков, окна на Ташкент | nano_banana_pro, 2k |
| s2 | у окна: трое за мониторами, вид на город и телебашню | nano_banana_pro, 2k |
| s3 | фасад ночью, ровная сетка окон, люди работают | nano_banana_pro, 2k |
| i1–i3 | наши макеты на мониторах: tovar, Karomat, кухни «в Ташкенте» (скриншоты из `docs/screens/*` как образец) | nano_banana_pro, 2k |
| v1 | пролёт по офису к окну (s1 → s2), 5 с | kling3_0 std |
| v2 | вылет в окно, разворот к зданию (s2 → s3), 6 с | kling3_0 pro |

Ушло 30 кредитов (на счету было 31,5). Исходники в репозиторий не кладём (≈40 МБ) — они в
истории генераций Higgsfield.

## Монтаж

`film.py` — без модели, только ffmpeg и numpy: общий грейд (бирюза в тенях,
янтарь в светах), виньетка, зерно, переходы, полосы кино 2.39:1. Финал — сам
фасад s3: окна, которые складываются в DEVUZ, зажигаются тёплым светом по
буквам с дрожью ламп, остальные окна гаснут вполовину, люди внутри видны.
Шрифт букв 5×5 окон, сетка фасада — 32 окна × 9 этажей (`PANE_X0`, `FLOORS`).

```
FILM_SRC=<папка с s3.png, i1-i3.png, vid/v1.mp4, vid/v2.mp4> python3 scripts/film/film.py out/film.mp4
```

Выходит `film.mp4` (с полосами, 1280×720 — посмотреть и переслать),
`film-site.mp4` (без полос, для сайта) и `film-poster.webp`.
