# Макет Sunday Event Agency (sunday.uz): исходники

Задание владельца DevUz, 09.11.2026: «Делаем макет для Sunday.uz». По навыку
`mockup`: эталонный промпт, цена — по слову владельца (ниже),
админка по Greenwell, Cargo Pro и Glassy, Higgsfield до 10%.

Их сайт не открывается (503), в архиве — заглушки: `BEFORE.md`. Факты — из
их Instagram, Telegram, Facebook и Яндекс Карт: `SOURCES.md`. Разведка —
`docs/research/sunday.md`, снимки — `docs/screens/sunday/`.

## Страницы (ru и uz)

- `""`, `uz` — видео DevUz (`dzIntroSolo`), за ним **залёт в центр их
  розетки**: камера через `viewBox`, три слоя лепестков поворачиваются в
  разные стороны, надпись SUNDAY уходит, внутри тёмный вечерний зал —
  гирлянды загораются по очереди, свечи на длинном столе, счёт 2009 → 2026,
  кругом раскрывается зал (иллюстрация). Дальше «Что посмотреть первым»,
  «Как проверить», «Предложение DevUz Studio».
- `site`, `uz/site` — сайт: первый экран на зале с параллаксом и
  вращающейся розеткой, бегущая строка, четыре направления (список и сцена),
  поводы лентой вбок, шаги с линией по прокрутке, о студии, связь. Допы (у
  каждого `data-addon`, тумблер первой страницы его прячет): смета
  (`#calc`), подбор концепции (`#quiz`), свободные даты (`#dates`), работы
  с фильтром (`#works`), кабинет пары (`#cab`), приглашение с ответами
  (`#rsvp`), бот (`#tgbot`), страницы под поиск (`#seo`), панель (`#admin`).
- `panel`, `uz/panel` — вход (телефон или Telegram, демо-код 1234), «Смотреть
  как: Владелец / Менеджер» (менеджер не видит бюджеты), Glassy V7 + CRM
  поверх зала: сводка, заявки, даты (календарь), гости, история, CSV.

Главное действие — их Telegram @sundayeventagency с готовым текстом и звонок.

## Связь сайта и панели

Память браузера: сайт пишет `sn-req-1` (заявки), `sn-hold-1` (брони дат),
`sn-rsvp-1` (ответы гостей); панель — статусы заявок и `sn-dates-1` (занято
/ свободно). Демо-занятость считается одним правилом (`demoBusy`) и на
сайте, и в панели. Конструктор — `sn-cfg-1`, `sn-offer-1`; панель —
`sn-pn-1`, `sn-log-1`.

**Ловушки**: «ООО «[[t:0]] Group»», «АО «[[t:1]] Bank»», ресторан
«[[t:2]]» в приглашении; числа камеры, плавности, концепции квиза и
выгрузки — с меткой `/*~*/`. Локально `serve.mjs` ставит «DemoN».

## Порядок

1. `node scripts/protos/sunday/gen.mjs` → `out/pages.json` и
   `content/proto-bundles/sunday.json`; падает на кириллице в узбекской
   странице, длинном тире и подписи панели без перевода (`ui.mjs`).
2. `node --import ./tests/alias-hook.mjs --import ./tests/tsx-hook.mjs
   scripts/proto-plain.mjs sunday` — «Чисто».
3. `node scripts/protos/sunday/serve.mjs`, затем
   `node scripts/protos/sunday/shots.mjs <папка>` (390, 768, 1440).

Картинки — `public/protos/sunday/`: восемь иллюстраций Higgsfield
(GPT Image 2.6) в их цветах, без людей и надписей, на страницах подписаны.

В базе — запись `protos` с `facts.bundle = "sunday"` (токен `2pxLxPGW…`, зерно отпечатка там же). Правка вёрстки сдвигает признаки отпечатка: после неё пересчитать `stamp` тем же зерном.
