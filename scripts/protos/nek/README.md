# Макет Nek Dental Studio (Тбилиси, Ваке, ул. Палиашвили, 65): исходники

Задание владельца DevUz, 10.11.2026: «Делаем премиальный макет для клиники. У
них сайта нет, но есть другие ресурсы, всю инфу вытащи от туда. Сайт 1000$, с
допами должно быть вместе не дороже 3000$. Мы делали для Сияния Севера, возьми
от туда фишки какие-то и используй мастер промпт. Используем mcp higgsfield, не
более 10%. Mcp используем для отрисовки скролл истории, как мы делали для
Сияния Севера». Сайта нет (`BEFORE.md`), факты — `SOURCES.md`, разведка —
`docs/research/nek.md`, снимки — `docs/screens/nek/`.

Языки: английский (главная), грузинский (`ka`) и русский (`ru`): посты клиники
на грузинском и английском, приём на трёх языках. Условий макета на грузинском
нет — грузинская страница ведёт на английские.

## Что взяли у «Сияния Севера»

- **Пролёт через клинику по прокрутке**: у них дверь → коридор → ресепшен →
  кабинет; здесь ресепшен со знаком → влёт сквозь лепестки цветка-знака →
  лаунж с бирюзовыми креслами → кабинет с фиолетовым креслом → макро зуба после
  реставрации. Главы с их словами встают поверх кадров. Счёт загрузки до 100%.
- **Запись в два нажатия** шторкой «день + время», дальше — их канал с готовым
  текстом (у «Сияния» SMS, здесь WhatsApp на их номер; есть ли WhatsApp —
  уточнить), звонок с нижней панели на телефоне.
- **Квиз**, **чат** с ответами из вопросов клиники, **панель**, где запись с
  сайта первой строкой, а статус виден пациенту в «Моей записи».
- **Вопросы** с плавной высотой (`grid-template-rows`).

Своё: слои реставрации ползунком (их главная услуга, «форма, цвет и
естественная эстетика»), план визита для приезжих (в Тбилиси клиники продают
лечение иностранцам, у них в отзывах пациентка из Германии).

## Пролёт: Higgsfield, 238 кредитов из 3 272 (7%)

- 10 ключевых кадров Nano Banana 2.1, 4K, опорой их фото из Instagram:
  5 широких и 5 вертикальных, 3 кредита за кадр.
- 8 переходов MiniMax H3, 2K, 10 с, кадр начала и конца, 20 кредитов за
  ролик: 4 широких компьютеру и 4 вертикальных телефону.
- Первая версия (4 ролика по 6 с, каждый 4-й кадр, 158 кадров, 63 кредита)
  снята: владелец, 10.11.2026, «Переходы абсолютно не плавные… слайдшоу».

`SCENE_KEY=<64 hex> python3 -I scene.py <папка 16:9> <папка 9:16>` (в каждой
`v1..v4.mp4` и `k1..k5.png`) берёт каждый второй кадр: 485 на пролёт,
компьютеру 1280×720, телефону 720×1280, и шифрует AES-256-GCM
(`public/protos/nek/seq/{d,m}/*.bin`). Ключ: `app.SCENE_KEY_NEK` в хранилище
секретов, макет получает его маршрутом `app/proto/[token]/promo/scene`
(`SCENES` в `lib/proto/promo.ts`). Открыты только постер (первый кадр) и
ключевые кадры для спокойной версии (`prefers-reduced-motion`).
`PREVIEW=<путь> python3 -I scene.py …` даёт лист проверки без шифра.
`land.js` смешивает два соседних кадра по доле прокрутки и заранее
распаковывает кадры по ходу; в памяти распакованных не больше `MAXB`
(телефон 28, компьютер 64). Сцена 1000vh. Реже каждого второго кадра не
резать.

## Защита

Условия макета в подвале каждой страницы, отпечаток стилей при показе,
ловушки: `[[t:0]] Travel` (демо-пациент в панели) и `Hotel [[t:1]]` (демо-отель
у приезжих), числа скриптов с `/*~*/`. На английской и грузинской страницах
ловушка — латиницей (`latinTraps` в `lib/proto/stamp.ts`).

## Сборка и проверка

1. `node scripts/protos/nek/gen.mjs` → `content/proto-bundles/nek.json`.
2. `node --import ./tests/alias-hook.mjs --import ./tests/tsx-hook.mjs scripts/proto-plain.mjs nek` — «Чисто».
3. `node scripts/mockup-plans.mjs` после правки цен в `plan.mjs`.
4. Локально: `SCENE_KEY=… node scripts/protos/nek/serve.mjs`, затем
   `node scripts/protos/nek/shots.mjs <папка> 390,768,1440 [ka|ru]` — снимки,
   ошибки консоли, прокрутка вбок, цикл «запись → панель → статус на сайте».
5. Держит `tests/proto-bundles.test.ts` («Nek Dental Studio: …»).
