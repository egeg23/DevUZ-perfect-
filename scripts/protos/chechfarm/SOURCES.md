# Картинки макета CZECHFARM

Все картинки — сгенерированы для макета в Higgsfield, модель nano banana 2.1,
4K, 26.10.2026. Ни одной чужой фотографии, ни одного препарата, упаковки,
надписи или логотипа: абстрактное стекло, лист, глобус и блоки.

| Файл | Что | Где |
|---|---|---|
| `hero-*.webp`, `hero-m-1080.webp` | стеклянная капсула, шар и диск на камне, лист; ПК 16:9 и телефон 9:16 | первый экран главной |
| `globe-*.webp` | стеклянный глобус с золотыми линиями маршрутов | «Партнёрам» |
| `steps-*.webp` | семь стеклянных блоков по возрастанию, бирюза → золото | «Инвесторам» |
| `open-*.webp`, `open-m-1080.webp` | та же сцена, капсула раскрыта на бирюзовую и золотую половины | конец сцены первого экрана |
| `seq/fNN.bin` | 48 кадров ролика MiniMax H3 Max (768p, 5 с) от `hero` к `open`, зашифрованы (`scene.py`) | сцена первого экрана на компьютере |
| `flask-*.webp` | колба с ростком в воде на льне | «О компании» |
| `studio-2048.webp` | тёмная студия, панорама 360° (21:9, растянута до 2:1) | отражения в буквах заставки |
| `intro3d.js` | заставка: three.js r170 и наш код (`intro/intro.js`) | главная, после видео DevUz |
| `icon.svg`, `apple-180.png` | знак-концепт | вкладка |

Расход: 7 картинок nano banana и один ролик MiniMax, около 32 кредитов (6-8% баланса по слову владельца). Заставка, 27.10.2026: одна панорама nano banana 2.1, 4K, 3 кредита (из разрешённых 5% ≈ 15).
