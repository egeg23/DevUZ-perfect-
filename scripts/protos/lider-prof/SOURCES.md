# Снимки прототипа LIDER PROF PROEKT

Все визуализации — с lider-prof.uz, раздел «Проекты» (их API
`api.lider-prof.uz/api-admincab/Project/getAllProject`, поля `mainImageUrl`
и `assets`), скачаны 12.10.2026, по одному файлу с паузой. Логотипы
заказчиков — блок «Нам доверяют» (`Partner/getAllPartner`). Ничего не
рисовали нейросетью и не увеличивали: каждый файл не шире исходника.
