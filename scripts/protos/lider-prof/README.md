# Прототип LIDER PROF PROEKT (lider-prof.uz) — исходники

Архитектурная студия из Ташкента: общественные и жилые здания, генпланы,
ландшафт, интерьер. Четыре страницы на двух языках (ru, uz): главная,
`proekty` (61 проект с фильтром), `proekt?id=<номер>` (одна страница на все
проекты, проект по номеру из их API), `plan` («Что дальше»). Исследование и
конкуренты — `docs/research/lider-prof.md`, фото — `SOURCES.md`, заходы
21st.dev — `21ST.md`.

Собран на движке Enotmebel (`scripts/protos/enotmebel`): заставка, история
при прокрутке по Engelberg v2, жидкое стекло, конструктор, «было / стало».

Главная — одна история при прокрутке, масштаб как у работы студии: генплан
Олимпийского центра с высоты → чертёж фасада становится зданием (окно с
рендером едет по чертежу, этапы загораются на стекле) → внутрь, спортзал и
зал детского сада → махалля «Qadrdon» сверху → пролёт сквозь проекты →
цифры студии и заказчики → карта городов, где стоят проекты → финал. После
истории: услуги по этапам, проекты с фильтром, расчёт проекта с брифом и
планом, просмотр 360°, заказчики, отзыв, карта, контакты.

- `gen.mjs` собирает `out/pages.json` и `content/proto-bundles/lider-prof.json`
  (lib/proto/bundles). Ссылки — через `__PROTO_BASE__`, отпечаток ставится при
  показе зерном из `protos.stamp`.
- `logo.mjs` — логотип геометрией (буквы по их logo.png, «Ø» с чертой),
  просвет «O» второй строки — цель влёта заставки.
- `intro.js` — промо DevUz Studio, затем буквы LIDER PROF PROEKT вырастают от
  строки, как здания, на чертёжной сетке, внутри — их рендер кампуса МГТУ;
  камера влетает в просвет «O» на первый экран. Раз за визит, тап ведёт
  дальше, «Пропустить» — сразу на сайт, без движения заставки нет.
- `story.js` — история (время в экранах, только transform и opacity, без
  перехвата прокрутки). Снимки глав грузятся очередью по два.
- `client.js` — Telegram студии с готовым текстом, очередь превью по три
  (урок enotmebel: залп картинок nginx отбивает с 429), фильтр, страница
  проекта с галереей, расчёт, 360°, «было / стало», конструктор.
- `plan.mjs` — конструктор: сайт 1 700 $, все допы 1 300 $, итог 3 000 $.
- `projects.json` — 61 проект из их API (названия, описания, показатели на
  ru и uz, какие кадры есть), `sizes.json` — размеры исходных кадров. Оба
  пишет подготовка (см. `SOURCES.md`).
- `photos.py` — все изображения в `public/protos/lider-prof/`; `shots.mjs` —
  «было / стало» (их сайт и прототип, компьютер и телефон).
- `serve.mjs` — `node serve.mjs`, затем `http://localhost:4797/proto/<43 символа>/`.
- `check.mjs` — Chromium 390×844 и 1440×900: заставка играет, пропускается
  тапом и кнопкой, без движения её нет, горизонтальной прокрутки нет ни на
  одной странице, ошибок нет, снимки.

Перед сдачей: `node --import ./tests/alias-hook.mjs --import
./tests/tsx-hook.mjs scripts/proto-plain.mjs lider-prof` — «Чисто».

Модель прототип не вызывает: ни ProxyAPI, ни `/api/proto-ai`.
В базе — запись `protos` с `facts.bundle = "lider-prof"`, `auto = false`.
