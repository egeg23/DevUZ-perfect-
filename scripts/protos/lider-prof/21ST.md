# Заходы 21st.dev в прототипе LIDER PROF PROEKT

Брали только компоненты под MIT (лицензия видна на странице компонента). Код
каждого захода свой, на чистом CSS и JS, без React и библиотек: прототип —
страница без сборки. Aceternity и React Bits не берём (закрытая лицензия и
Commons Clause).

| Блок | Заход | Автор на 21st.dev | Где в коде |
|---|---|---|---|
| Кнопки «Обсудить проект» | Shimmer Button: блик пробегает по кнопке | dillionverma (Magic UI) | `.shim`, `style.css` |
| Карточки проектов | Magic Card: пятно света за курсором | dillionverma (Magic UI) | `.spot`, `client.js` |
| | Tilt: карточка наклоняется за курсором | ibelick (motion-primitives) | `.tilt`, `client.js` |
| Заказчики | Marquee: лента логотипов | dillionverma (Magic UI) | `.mq-row` |
| Цифры студии | Number Ticker: числа набегают | dillionverma (Magic UI) | `count()`, `story.js` |
| Итог конструктора | Border Beam: луч бежит по рамке | dillionverma (Magic UI) | `.kit-total::before` |

Своё, без 21st.dev: история при прокрутке по движку Engelberg v2
(`story.js`), чертёж, который становится зданием (два встречных transform),
жидкое стекло с преломлением (`#lq`), заставка с буквами-зданиями и влётом
в «O» (`intro.js`), просмотр 360° с инерцией и наклоном телефона, расчёт
проекта, движения появления «этаж», «плита», «чертёж».

Все движения — `transform` и `opacity`; при `prefers-reduced-motion`
заставки нет, история стоит списком, ленты не едут.
