# Заходы 21st.dev в прототипе Aipply Academy

Брали только компоненты под MIT (лицензия видна на странице компонента):
Magic UI (@dillionverma) и motion-primitives (@ibelick). Код каждого захода
свой, на чистом CSS и JS, без React и библиотек: прототип — страницы без
сборки. Aceternity и React Bits не брали (закрытая лицензия и Commons Clause).
