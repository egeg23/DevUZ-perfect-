# Заходы 21st.dev и референса в макете архбюро

Минимализм по референсу (yodezeen.com, разбор — `docs/research/arch-bureau.md`):
светло-серый фон `#f2f0f0`, один гротеск (у них Helvetica Neue и Neue Haas,
у нас Inter Tight с кириллицей, 400 и 700), заголовки капсом с плотным
трекингом, подписи мелким капсом, тонкие линии, шапка в три колонки.

С 21st.dev брали только компоненты под MIT (лицензия на странице
компонента). Код каждого захода свой, на чистом CSS и JS, без React: макет
— страница без сборки.

| Блок | Заход | Автор на 21st.dev | Где в коде |
|---|---|---|---|
| О бюро | Text Reveal: слова проявляются прокруткой | dillionverma (Magic UI) | `.stmt`, `stmtFx()` |
| Бегущая строка | Scroll Based Velocity: скорость и направление от прокрутки | dillionverma (Magic UI) | `.velo`, `veloStep()` |
| Заголовки, абзацы | Blur Fade: строки поднимаются из-под маски (без размытия) | dillionverma (Magic UI) | `.ln`, `[data-lines]` |
| Ссылки, меню, кнопки | Text Roll: буквы перекатываются при наведении | ibelick (Motion Primitives) | `.roll`, `roll()` в `gen.mjs` |

С референса (свой код):

| Блок | Приём yodezeen | Где в коде |
|---|---|---|
| Первый экран | закреплённая сцена, кадры сменяют друг друга прокруткой, подпись проекта меняется, кадр отъезжает | `.hero`, `heroFx()` |
| Пролёт | кадры на canvas по прокрутке (их блок Stillstone) | `.fly` |
| Проекты | большие кадры, подписи мелким капсом, фильтр «Мы делаем»; кадр приближается к рамке прокруткой | `.pj`, `zoomFx()` |
| География | заголовок в три строки, карта точками со шкалой градусов, барабан городов крутится прокруткой | `.geo`, `drumFx()` |
| Услуги | список-аккордеон на тонких линиях | `.sv` |
| Что будет на сайте | оглавление, как у их монографии | `.toc` |
| Курсор | точка с mix-blend difference, над кадром вырастает в круг со словом | `.cursor` |
| Переход в проект | кадр раскрывается маской на весь экран | `cover()` |

Lenis (плавный скролл) у референса есть, у нас нет: прокрутку не
перехватываем (правило макетов). Все движения — `transform` и `opacity`;
при `prefers-reduced-motion` сцены стоят, слова видны сразу, строка не едет.
