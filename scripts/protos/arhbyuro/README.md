# Макет сайта архитектурного бюро — исходники

Имиджевый сайт и портфолио архбюро по ТЗ клиента (референс yodezeen.com:
минимализм, полноэкранные изображения, плавные переходы). Демо DevUz
Studio: 3–4 сильных блока, а не весь сайт. Языки RU и EN, как в ТЗ.
Исследование сайтов в том же духе — `docs/research/arch-bureau.md`.

Название бюро в ТЗ нет: **LINIA — рабочее имя**, меняется в одном месте
(`BRAND` в `data.mjs`) и встаёт везде. Нужны настоящее название и логотип.

## Что показано

1. **Первый экран**: промо DevUz Studio (как в DomTut), затем знак бюро:
   линии здания прочерчиваются, камера влетает в дверной проём. Дальше
   «видео» бюро во весь экран — медленный проезд вдоль фасада, рендер
   Blender (туда и обратно, без шва). На телефоне, при экономии трафика и
   медленной сети — картинка (`hero-m.webp`), как требует ТЗ.
2. **Пролёт по прокрутке**: 180 кадров Blender на canvas — генплан сверху →
   облёт и спуск к фасаду → над водой к открытой створке → гостиная и двор.
   Кадр следует за прокруткой (без перехвата), кадры грузятся очередью по
   четыре: сначала каждый 16-й, потом гуще. На телефоне свой вертикальный
   рендер (`f/m`), на ПК — `f/d`. Без движения — четыре кадра подряд.
3. **Проекты**: полноэкранные кадры с текстом через один, фильтр по услугам
   (собирается сам по полю проекта), карта мира точками с проектами,
   услуги, у каждой свои проекты. Страница проекта: кадр во весь экран,
   короткое и полное описание, кадры и текст через один, видео, карта с
   координатами, «Следующий проект». **Переход**: кадр карточки раскрывается
   маской на весь экран (GSAP), и страница проекта начинается с него.
4. **Большое меню** с фоном у каждого пункта и **форма «Связаться»**,
   выезжает справа с любой страницы, без перезагрузки. Форма честная: в
   макете заявка никуда не уходит, и это сказано на экране.

Плюс блок «Что будет на рабочем сайте» — пункты ТЗ: Strapi, Next.js и GSAP,
PageSpeed 90+, SEO, RU/EN, сервер и сдача.

Проекты демо: дом, интерьер, башня и павильон построены нами в Blender
(`scripts/blender/arhbyuro`), чужих фото и чужих зданий нет — фото Unsplash
отсюда недоступны, а выдавать известные здания за работы бюро нельзя.

## Файлы

- `data.mjs` — бренд, проекты, услуги, меню, пункты ТЗ [ru, en].
- `gen.mjs` — собирает `out/pages.json` и `content/proto-bundles/arhbyuro.json`.
  Ссылки — через `__PROTO_BASE__`, отпечаток ставится при показе зерном
  из `protos.stamp`.
- `site.css`, `site.js` — сайт; `intro.css`, `intro.js` — заставка.
- `worldmap.py` → `worldmap.json` — суша точками (Natural Earth 1:110m).
- `icons.py` — значки вкладки.
- `serve.mjs` — `node serve.mjs`, затем `http://localhost:4812/proto/<43 символа>/`.
- `shots.mjs` — Chromium 1440×900 и 390×844: первый экран, 4 кадра пролёта,
  проекты, карта, услуги, ТЗ, меню, форма, переход в проект; ошибки и
  горизонтальная прокрутка.

GSAP 3.13 (`public/protos/arhbyuro/gsap.min.js`, бесплатная лицензия
GreenSock) лежит у нас: со стороны макет грузит только шрифты Google.

## Кадры — из Actions

Рендер — задача «Макет архбюро — рендер Blender», результат в ветке
`renders/arhbyuro` (см. `scripts/blender/arhbyuro/README.md`). В `public/`:

```sh
git fetch origin renders/arhbyuro
R=renders/arhbyuro; P=public/protos/arhbyuro
git checkout origin/renders/arhbyuro -- $R/flight-horizontal/d $R/flight-vertical/m $R/hero-horizontal $R/stills-horizontal
mkdir -p $P/f && mv $R/flight-horizontal/d $P/f/d && mv $R/flight-vertical/m $P/f/m
cp $R/hero-horizontal/hero-*.mp4 $R/hero-horizontal/poster-*.webp $P/
cp $R/stills-horizontal/s-*.webp $P/ && rm $P/s-*-full.webp
cp $P/f/m/0085.webp ... # hero-m.webp — кадр 85 вертикального пролёта, см. ниже
```

`hero-m.webp` — кадр 85 из `flight-vertical/mhq` (1080×1920): фасад через
бассейн, картинка первого экрана на телефоне.

Перед сдачей: `node --import ./tests/alias-hook.mjs --import
./tests/tsx-hook.mjs scripts/proto-plain.mjs arhbyuro` — «Чисто».

Модель макет не вызывает: ни ProxyAPI, ни `/api/proto-ai`. В базе — запись
`protos` с `facts.bundle = "arhbyuro"`, `auto = false`.
