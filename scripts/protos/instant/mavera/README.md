# Снимок макета MAVERA («Премиум»)

Шаблон «Недвижимость» в «Макете в боте» (`lib/proto/instant/nedv.ts`) стоит на
нашем макете MAVERA, вариант 03 «Премиум» (светлый зал). Сам макет живёт на
витрине (репозиторий витрины, `app/mavera/premium`, `components/mavera`,
`app/mavera.css`) и написан на React, поэтому сюда положен снимок.

- `premium.css`: собранные стили страницы «Премиума» с витрины. Из общего файла
  стилей витрины оставлены только правила, классы которых есть на странице
  (палитра «слоновая кость», `data-world="premium"`), без шрифтовых файлов,
  без заставки витрины и без правил других проектов. Текст правил не менялся.
- `site.js`: поведение макета простым скриптом без библиотек (в макете это
  компоненты React): появление разделов (`Rise`), параллакс первого экрана
  (`CinemaHero`), кинолента (`FilmRail`), генплан и шахматка (`Genplan`,
  `Picker`), заявка.

Как обновить `premium.css`: поднять витрину локально (`next dev`), открыть
`/mavera/premium`, прокрутить страницу до конца, собрать список классов со
страницы и оставить из файла стилей правила только с ними.

Чего в снимке нет и быть не должно: названий ЖК, цен, площадей, сроков,
контактов и фотографий MAVERA. Это держит `content/proto-instant/tails.json`.
