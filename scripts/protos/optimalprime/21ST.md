# Блоки по мотивам 21st.dev и наших эталонов

Код каждого блока написан здесь заново, на чистом JS и CSS, без библиотек.
Движение — только transform и opacity, при «меньше движения» всё стоит.

| Блок | Откуда приём | Где в макете |
|---|---|---|
| Scroll Sequence — кадры камеры по прокрутке | наш, SamAuto и Oson Apteka | залёт в знак на первой странице |
| Liquid Glass — размытие, блик рамки за пальцем | asmo, Oson Apteka, Neoline | шапка, «18 лет», плитки первого экрана, итог тарифа, ведомость |
| Parallax Layers | наш | девять плиток знака на разной глубине и фото города |
| Animated Tabs — плашка переезжает пружиной | 21st.dev, Animated Tabs | режим налогов в конструкторе и в календаре |
| Vertical Tabs — список слева, панель справа | 21st.dev, Tabs / Feature Tabs | четыре направления услуг |
| Pricing Calculator — ползунки с итогом | 21st.dev, Pricing | конструктор тарифа и «Предложение DevUz Studio» |
| Scroll Velocity — строка ускоряется от прокрутки | Cosmo World, Neoline | услуги под первым экраном, клиенты двумя рядами |
| Timeline / Steps — линия заполняется по прокрутке | 21st.dev, Timeline | «Как начать сотрудничество» |
| Shimmer Button — блик по кнопке | 21st.dev / Magic UI | все золотые кнопки |
| Reveal on toggle — данные закрыты полосами | наш | тайна зарплат: «видит сотрудник» / «видит Optimal Prime» |
| Multi-step Quiz | 21st.dev, Stepper | проверка учёта за 2 минуты |
| Bottom Sheet | 21st.dev, Drawer | «Моя заявка» со статусом из панели (на ПК — справа) |
