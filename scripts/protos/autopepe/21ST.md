# Блоки по мотивам 21st.dev, Awwwards и наших эталонов

Код каждого блока написан здесь заново, на чистом JS, CSS и GLSL, без
библиотек (кроме three.js в заставке). Движение — только transform, opacity
и шейдер; при «меньше движения» всё стоит.

| Блок | Откуда приём | Где в макете |
|---|---|---|
| Compare / Before-After Slider — шторка | 21st.dev, Compare | «Przed i po» на их фото, сама показывает, что тянется |
| Spotlight Card — подсветка за курсором | 21st.dev, Spotlight Card | карточки услуг (`--mx`, `--my`) |
| Shimmer Button — блик по кнопке | 21st.dev / Magic UI | главные кнопки (`.btn-a::after`) |
| Scroll Velocity — строка ускоряется от прокрутки | 21st.dev, Scroll Velocity (как Cosmo World) | их выгоды и услуги под первым экраном |
| Liquid Glass — размытие, блик рамки за пальцем | 21st.dev, Liquid Glass (как Neoline) | шапка, плашки первого экрана, подписи сцены, итог калькулятора |
| Word Reveal — слова заголовка выезжают по очереди | 21st.dev, Text Animate | первый экран |
| Interactive car configurator — схема машины | Awwwards, конфигураторы автосалонов; у кузовных в Варшаве не нашли | калькулятор: нажатие на деталь → вид ущерба → вилка цены |
| Live paint shader — лак, который ловит свет | Awwwards, сайты детейлинга и автобрендов | первый экран, карточка выбора |
| Sticky Scroll Scene | наш, как «Радар в деле» у Neoline | «Od wgniecenia do lustra»: доска с полосами, вмятина, выдавливание, царапины, полировка |
| Залёт камерой в бренд | Neoline и CHECHFARM | заставка после видео DevUz |
