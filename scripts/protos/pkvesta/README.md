# Прототип ПК Веста (pkvesta.kz) — исходники

Завод быстровозводимых стальных зданий, офис в Алматы. Шесть страниц на
русском: главная, `katalog`, `obekt` (?id=213|203|199|204|217), `raschet`,
`zavod`, `plan` («Что дальше»). Собран на каркасе ShahaR.Uz
(`scripts/protos/shahar`): шапка, промо DevUz, конструктор, «было / стало».
Исследование — `docs/research/pkvesta.md`, снимки — `SOURCES.md`.

- `gen.mjs` собирает страницы в `out/pages.json` и сборку для сервера
  `content/proto-bundles/pkvesta.json` (lib/proto/bundles). Ссылки — через
  `__PROTO_BASE__`, отпечаток ставится при показе зерном из `protos.stamp`.
- `intro.js` — заставка главной: промо DevUz Studio, затем логотип завода
  «PK · домик · Vesta» собирается, жёлтые ворота поднимаются, и камера
  влетает в проём на чертёж каркаса с первого экрана.
- `client.js` — параллакс чертежа, смена слова, счётчики, сцена «чертёж →
  каркас → здание» (липкий кадр, прокрутка своя), лента объектов вбок,
  линия истории, расчёт по размерам → WhatsApp завода, каталог, объект,
  «было / стало», конструктор. Только transform и opacity.
- `plan.mjs` — конструктор: сайт 2 300 $, все допы 1 600 $, итог 3 900 $.
- `photos.py` — чертёж из визуализации каркаса, кадры сцены, фото объектов,
  значок вкладки.
- `serve.mjs` — локальный показ: `node serve.mjs`, затем
  http://localhost:4792/proto/<43 символа>/

Перед сдачей: `node --import ./tests/alias-hook.mjs --import
./tests/tsx-hook.mjs scripts/proto-plain.mjs pkvesta` — должно быть «Чисто».
