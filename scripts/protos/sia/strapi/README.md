# Панель сайта SIA на Strapi

Панель архитектурного бюро SIA (sia88.ru) на Strapi 5, бесплатной версии
(Community, лицензия MIT). Ставится на сервер бюро, платы за неё нет.
Решение владельца, 22.10.2026: «Админка должна быть Strapi».

## Что внутри

| Раздел в панели | Тип | Что хранит |
|---|---|---|
| Проекты | коллекция | код, раздел (архитектура / интерьер), название, площадь, срок, дата, описание, этапы, обложка, чертёж, фото, «на главной», порядок, SEO |
| Тип объекта | коллекция | загородный дом, клубный дом, клиника… (связь с проектами) |
| Услуги | коллекция | услуга, описание, цена и срок, фото |
| Новости и выставки | коллекция | заголовок, даты, место, текст, фото |
| Коллектив | коллекция | имя, должность, фото, порядок |
| Заявки | коллекция | имя, телефон, почта, сообщение, откуда, статус, заметки |
| Журнал | коллекция | кто, что и когда изменил (пишется сам) |
| Главная | одиночный | блоки главной: первый экран, цифры, текст, проекты, галерея, услуги, этапы, выставки, коллектив, контакты; у каждого заголовок, текст, фото, «скрыть»; порядок перетаскиванием |
| Контакты | одиночный | телефоны, почта, адрес, метро, часы, WhatsApp, Telegram, соцсети |

Подписи полей и столбцы списков по-русски (`src/labels.js`), язык панели
русский по умолчанию (`src/admin/app.js`).

## Роли

Кроме встроенного Super Admin (владелец), при каждом запуске
(`src/index.js`) заводятся и приводятся в порядок:

- **Редактор сайта**: проекты, услуги, новости, коллектив, главная,
  контакты, медиатека, публикация; журнал только читает; заявки не видит.
- **Медиа**: медиатека и фото в проектах, новостях, услугах, коллективе и
  блоках главной. Тексты не меняет: Strapi отбрасывает такие поля.
- **Менеджер заявок**: заявки (статус, заметки), проекты только читает.

Пользователей заводит владелец: «Настройки» → «Пользователи» →
«Пригласить», роль из списка. Свои роли и права по полям Strapi позволяет
и в бесплатной версии.

## Что платное у Strapi и чем заменено

- Журнал действий (Audit logs, Enterprise): свой, коллекция «Журнал»,
  пишется промежуточным слоем документов (`logMiddleware`).
- История версий, релизы, согласование, SSO (Growth и Enterprise): не
  используются.

## Сайт и панель

Сайт читает опубликованное без ключа (`/api/projects`, `/api/services`,
`/api/news-items`, `/api/team-members`, `/api/object-types`, `/api/home`,
`/api/contact`). Заявку с сайта можно только отправить: `POST /api/leads`
с именем, телефоном или почтой, сообщением; статус и заметки посетитель
не задаёт (`src/api/lead/controllers/lead.js`), прочитать заявки без входа
нельзя.

## Запуск

Node 20-24. Для работы — PostgreSQL, для пробы хватает SQLite.

```bash
cp .env.example .env      # и заменить все tobemodified своими ключами
npm ci
npm run build
npm run seed              # первое наполнение: 65 проектов, услуги, коллектив, выставки, главная, контакты, 144 фото
npm run start             # панель: http://localhost:1337/admin
```

Фото для наполнения берутся из `SIA_IMAGES` (по умолчанию снимки макета,
`public/protos/sia` этого репозитория), данные — из `seed/data.json`.
Его пишет `../gen.mjs` вместе с макетом: одна правда для макета и панели.

Сервер для бюро: 2 ГБ памяти, PostgreSQL, nginx с HTTPS перед портом 1337,
папка `public/uploads` (или S3) в резервной копии вместе с базой. На наш
сервер студии панель не ставится.
