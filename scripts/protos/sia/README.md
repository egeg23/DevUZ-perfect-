# Макет нового сайта архбюро SIA (sia88.ru)

Клиент хочет обновить сайт. Всё на макете — с его сайта: 65 проектов архива
с кодами (APx182.1208, ИНт238.2606), тексты проектов и «Что было сделано»,
услуги с ценами и сроками, коллектив со снимками, выставки, адрес, метро,
часы, телефон, почта, WhatsApp, Telegram и соцсети. Снимки — рендеры бюро.
Ничего не дописано: лет на рынке на сайте бюро то 6, то 15, поэтому на
макете их нет.

## Мысль

Знак SIA — буквы из стальных ферм. Каркас прежде облика: каждый проект
сначала появляется **чертежом** (линии того же рендера, `assets.py`) и на
глазах становится рендером.

| Блок | Движение |
|---|---|
| Заставка | промо DevUz, затем стальные буквы SIA: фермы букв разлетаются и собираются в каркас виллы APx180.2606, лист светлеет до бумаги, каркас дорисовывается, сквозь него проступает чертёж того же дома, и чертёж стирается в рендер первого экрана |
| Первый экран | чертёж стирается в рендер; прокрутка сводит кадр в арку, по бокам «Архитектура и интерьер»; на ПК под курсором линза с чертежом |
| Цифры | разряды прокатываются, как счётчик |
| О бюро | слова бюро проявляются прокруткой |
| Архитектура | на ПК галерея едет вбок от прокрутки, чертёж карточки становится рендером у середины экрана; на телефоне то же столбиком |
| Пролёт | камера летит по рендерам бюро: вилла APx180.2606 снаружи (участок, фасад, уровни, бассейн), у спа уходит в стекло, за ним интерьер ИНт238.2606 проступает чертежом и становится рендером: зал с бассейном, спальня, галерея-сад; стеклянные карточки этапов со словами бюро |
| 3D-пролёт | 180 кадров Blender по прокрутке из макета архбюро; подписан как демонстрация: дом наш, по 3D-модели проекта бюро соберём такой же |
| Интерьеры | карточки ложатся стопкой, нижняя уходит вглубь |
| Бегущая строка | коды проектов и услуги, скорость и направление от прокрутки (Scroll Based Velocity, Magic UI) |
| Что проектируем | барабан типов объектов крутится прокруткой, рядом число проектов каждого типа |
| Папки бюро | архив по типам в стеклянных папках, проекты выходят веером (Glass Folder Cards, kedhareswer, MIT) |
| Архив | 65 строк с фильтром, за курсором плывёт обложка |
| Услуги | снимок открывается ламелями, как жалюзи |
| Этапы | линия прочерчивается прокруткой, шаги загораются |
| Выставки | контурные названия едут навстречу прокрутке |
| Переходы | стальные ламели закрывают экран с кодом проекта и открывают новую страницу |
| Проект | рендер стирает чертёж по прокрутке, подпись как штамп чертежа |

Скролл не перехватывается, всё на `transform` и `opacity`, при
`prefers-reduced-motion` всё стоит. Шапка прячется при прокрутке и
возвращается через 3 секунды. Главное действие — WhatsApp бюро с готовым
текстом, внизу экрана.

## Сборка

1. Выгрузка с сайта бюро (открытый WordPress API, ключ не нужен):
   `wp-json/wp/v2/posts?per_page=100` → `posts.json`, `wp-json/wp/v2/tags`
   → `tags.json`; обложки, снимки избранных и команды, логотипы — с
   `wp-content/uploads`.
2. `python3 -I extract.py <папка выгрузки>` → `data.json`.
3. `python3 -I lines.py <logo_footer.png> <apx180-2606-0.jpg>` → `lines.json`: фермы логотипа и каркас дома для заставки (нужен `opencv-python-headless`, только для сборки).
4. `python3 -I assets.py <src> <cov> <logo>` → `public/protos/sia` (WebP, чертежи).
5. `node gen.mjs` → `content/proto-bundles/sia.json`.
6. Проверка: `node --import ./tests/alias-hook.mjs --import ./tests/tsx-hook.mjs scripts/proto-plain.mjs sia` — «Чисто».
7. Снимки: `node serve.mjs`, затем `node shots.mjs <папка>`.

Штампы в текстах бюро, которые не пропускает проверка («уникальный», «не
просто …, а …»), поправлены словом в `FIX` (`gen.mjs`), смысл тот же.

## Панель сайта (`panel`)

Владелец DevUz, 19.10.2026: «админку им как у Greenwell, но под архитектурное
бюро: пользователи, роли, новости и фото в каждый раздел сайта, чтобы мы им
не были нужны». Страница `panel` (`panel.js`, `panel.css`), на главной блок
«Панель сайта» с панелью в окне браузера.

- **Разделы:** сводка, проекты (все 65 из архива, правка, черновик, новый
  проект, фото с обложкой и порядком), разделы сайта (заголовок, текст, фото
  каждого блока главной, порядок и видимость; список блоков — `SECS` в
  `gen.mjs`), новости и выставки, коллектив, медиатека, заявки (демо),
  пользователи и роли, журнал действий, настройки (контакты, заголовок и
  описание для поиска, «Сбросить демо»).
- **Роли:** Владелец (всё, не понижается), Администратор, Редактор, Медиа,
  Менеджер заявок и свои роли; права по каждому разделу «нет / просмотр /
  правка». «Вы смотрите как» сверху показывает панель глазами пользователя.
- **Хранение в макете:** состояние в `localStorage` (`sia-panel-1`), фото в
  IndexedDB (`sia-media`), сжаты в браузере до 2000 px WebP. Главная читает
  то же состояние (`site.js`, начало файла) и сразу показывает новости,
  правки архива, коллектив, контакты, заголовки, тексты, фото, порядок и
  скрытие блоков.
- Заявки в панели демо, без имён и телефонов. Пользователи демо — люди из
  коллектива бюро с их сайта, роли им назначены для показа.

## Вариант 2 (`v2`)

Тёмная страница по мотивам textura.agency: зерно, тонкий знак, серифные
названия, холодный голубой акцент. Главная и три блока: проекты списком,
направления (кадр закреплён, прокрутка меняет шаг), коллектив. Все снимки
ч/б; на ПК под курсором цвет расплывается из точки входа (размытый слой) и
медленно заливает кадр (чёткий слой), на телефоне — у середины экрана.
Только `opacity` и `transform`. Тумблер «Вариант 1 / Вариант 2» — на обеих
страницах. Файлы: `v2.css`, `v2.js`, `v2Page()` в `gen.mjs`.

## Наше промо (фильм «Сначала линия», 19.10.2026)

36 секунд, 9:16, 720p: ночь в бюро (Ладыжников ведёт линию на кальке,
Минасян вешает эскиз, Слухов у рендера) → рассвет на участке APx180.2606
(Янышев, каркас растёт) → вечер у готовой виллы, вся четвёрка на террасе →
карточка «Сначала линия. Потом дом.», sia88.ru. Кадры: Nano Banana по фото
коллектива и рендерам, видео: Seedance 2.5 (три акта по 12 с), монтаж и
переходы (в темноту, сдвигом вверх) — ffmpeg.

Лица — сотрудников бюро, сгенерированы ИИ по их фото: ролик только для
закрытого показа бюро, не для публикации без их согласия.

В макете ролик не файлом: зашифрованные куски HLS в
`public/protos/sia/promo/`, ключ — в хранилище секретов
(`PROMO_KEY_SIA`), выдаёт его только маршрут макета (lib/proto/promo).
Пересобрать: ffmpeg `-f hls -hls_time 4 -hls_key_info_file` тем же ключом
(ffmpeg ставит IV ноль на все куски, плейлист говорит то же), куски `p%d.ts`; длительности — в `PROMOS.sia.parts`.

Страница `panel` — та же панель в облике Strapi 5 (полоса значков, «Контент»
с типами коллекций и одиночными типами, фиолетовый акцент), работает в
браузере для показа. Настоящая панель — проект Strapi в `strapi/`.
