# Прототип GAZMETPROD SERVIS (europegas.uz) — исходники

ООО «GAZMETPROD SERVIS», Ташкент, Алмазарский район, Каракамыш 1/4, 11-А:
газобаллонное оборудование (метан и пропан, 3 и 4 поколение), программирование,
испытание баллонов, ремонт, фургоны из сэндвич-панелей и рефрижераторы.
Официальный дилер EuropeGAS (Польша) и E-XON (Китай). Две страницы на двух
языках (ru, uz): главная и `plan` («Что дальше»). Собран на движке Asmo Clinic
(`scripts/protos/asmo`): промо DevUz, сцена при прокрутке по Engelberg v2,
жидкое стекло, конструктор цены, «было / стало». Исследование и конкуренты —
`docs/research/europegas.md`, источники — `SOURCES.md`, заходы 21st.dev — `21ST.md`.

- `gen.mjs` собирает `out/pages.json` и `content/proto-bundles/europegas.json`
  (lib/proto/bundles). Ссылки — через `__PROTO_BASE__`, отпечаток ставится при
  показе зерном из `protos.stamp`.
- `logo.mjs` + `logo.json` — их логотип: ромб и пламя геометрией, буквы
  контурами Montserrat. Один символ на страницу (`#eg-logo`, `#eg-sign`).
- `art.mjs` — рисунки кодом: машина в разрезе с газовой системой, баллон на
  испытании, фургон Labo по слоям сэндвич-панели.
- `intro.js` — промо DevUz Studio, прочерчивается ромб, загорается пламя,
  проявляются буквы, камера влетает в пламя: оно становится просветом на первый
  экран. Раз за визит, тап ведёт дальше, «Пропустить» — сразу на сайт.
- `story.js` — история: знак и пламя → камера по газовой системе от баллона до
  форсунок, по магистрали бегут капли газа → испытание баллона по шагам →
  фургон разлетается на слои и собирается, на крышу встаёт холодильник →
  оборудование по орбите → запись.
- `client.js` — смена цвета между блоками, очередь превью по три, запись
  (машина, услуга, день → Telegram), калькулятор экономии на метане, срок
  испытания баллона с напоминанием в календаре (.ics), конструктор фургона,
  просмотр фото и документов, конструктор сайта.
- `plan.mjs` — сайт 1 700 $, допы на макете 790 $, сверх сайта 510 $, итог 3 000 $.
- `photos.py` — их снимки в `public/protos/europegas/` (WebP, без увеличения);
  `shots.mjs` — «было / стало» и значки вкладки; `serve.mjs` — `node serve.mjs`,
  затем `http://localhost:4807/proto/<43 символа>/`; `check.mjs` — Chromium
  390×844 и 1440×900.

Перед сдачей: `node --import ./tests/alias-hook.mjs --import
./tests/tsx-hook.mjs scripts/proto-plain.mjs europegas` — «Чисто».

Модель прототип не вызывает: ни ProxyAPI, ни `/api/proto-ai`. Сгенерированных
картинок нет. В базе — запись `protos` с `facts.bundle = "europegas"`, `auto = false`.
