# Заходы 21st.dev в прототипе GAZMETPROD SERVIS

Брали только компоненты под MIT. Код каждого захода свой, на чистом CSS и JS,
без React и библиотек: прототип — страница без сборки. Aceternity и React Bits
не берём (закрытая лицензия и Commons Clause).

| Блок | Заход | Автор на 21st.dev | Где в коде |
|---|---|---|---|
| Услуги | Bento Grid: сетка карточек разного размера | dillionverma (Magic UI) | `.bento`, `style.css` |
| Карточки услуг | Magic Card: пятно света за курсором | dillionverma (Magic UI) | `.spot-host`, `client.js` |
| Оборудование в истории | Orbiting Circles: значки по двум орбитам | dillionverma (Magic UI) | `.orbit`, `story.js` |
| Марки машин и партнёры | Marquee: бегущая строка, пауза при наведении | dillionverma (Magic UI) | `.mq`, `style.css` |
| Кнопки записи | Shimmer Button: блик по кнопке | dillionverma (Magic UI) | `.shim` |
| Итог калькулятора | Border Beam: луч по рамке | dillionverma (Magic UI) | `.calc-out::before` |
| Цифры компании, экономия | Number Ticker: числа набегают | dillionverma (Magic UI) | `count()`, `tickC()`, `.tm-n` |

Своё: заставка с влётом в пламя логотипа (просвет по форме пламени, evenodd на
canvas), камера по газовой системе с каплями газа по настоящему пути магистрали
(`getPointAtLength`), испытание баллона по шагам (пар, конденсат, кольцо
осмотра, весы, отметка), фургон веером по слоям сэндвич-панели, спидометр
экономии, напоминание об испытании файлом календаря, жидкое стекло с
преломлением (`#lq`), смена цвета страницы слоями, движения появления
«деталь встаёт», «защёлка», «баллон на подставку».
