# Блоки по мотивам 21st.dev и наших эталонов

Код каждого блока написан здесь заново, на чистом JS и CSS, без библиотек.
Движение — только transform и opacity, при «меньше движения» всё стоит.

| Блок | Откуда приём | Где в макете |
|---|---|---|
| Spotlight Card — подсветка за курсором | 21st.dev, Spotlight Card | карточки каталога (`--mx`, `--my`) |
| Shimmer Button — блик по кнопке | 21st.dev / Magic UI, как в CHECHFARM | все главные кнопки (`.btn-a::after`) |
| Animated Tabs — вкладки-пилюли | 21st.dev, Animated Tabs | разделы каталога |
| Scroll Velocity — строка ускоряется от прокрутки | Cosmo World | выгоды и радары под первым экраном |
| Text Reveal — слова загораются по прокрутке | Cosmo World | «Флагман X-COP», «Почему в официальном» |
| Glass Folder — папка с товарами | Cosmo World | «Всё для машины от одного бренда» |
| Liquid Glass — размытие, блик рамки за пальцем | asmo, CHECHFARM | шапка, плашки первого экрана, итог конструктора |
| Sticky Scroll Scene | наш, по уроку Engelberg | «Радар в деле» |
| Drag Turntable | SamAuto, из их фото | стенд X-COP 8900 |
