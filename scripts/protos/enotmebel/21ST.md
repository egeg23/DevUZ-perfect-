# Заходы 21st.dev в прототипе Enotmebel

Брали только компоненты под MIT (лицензия видна на странице компонента). Код
каждого захода свой, на чистом CSS и JS, без React и библиотек: прототип —
страница без сборки. Aceternity и React Bits не берём (закрытая лицензия и
Commons Clause).

| Блок | Заход | Автор на 21st.dev | Где в коде |
|---|---|---|---|
| Кнопки заказа | Shimmer Button: блик пробегает по кнопке | dillionverma (Magic UI) | `.shim`, `style.css` |
| Каталог | Magic Card: пятно света за курсором | dillionverma (Magic UI) | `.spot`, `client.js` |
| | Tilt: карточка наклоняется за курсором | ibelick (motion-primitives) | `.tilt`, `client.js` |
| Офисы | Marquee: лента галереи и логотипов заказчиков | dillionverma (Magic UI) | `.gal-row`, `.mq-row` |
| Гарантия | Accordion: ответ раскрывается, плюс поворачивается в крестик | ibelick (motion-primitives) | `.acc` |
| Итог конструктора | Border Beam: луч бежит по рамке | dillionverma (Magic UI) | `.kit-total::before` |

Своё, без 21st.dev: история при прокрутке по движку Engelberg v2 (`story.js`),
шарики наполнителя на canvas, пролёт сквозь модели, ткани столбиками, карта
доставки, жидкое стекло с преломлением (`#lq`), заставка ENOT (`intro.js`),
выбор ткани и цвета по настоящим образцам.

Все движения — `transform` и `opacity`; при `prefers-reduced-motion` заставки
нет, история стоит списком, ленты не едут.
