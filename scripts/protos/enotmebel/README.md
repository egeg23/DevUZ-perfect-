# Прототип Enotmebel (enotmebel.uz) — исходники

Бескаркасная мебель из Ташкента: бин-бэги, кресла-мешки, лежаки, 15 моделей.
Две страницы на двух языках (ru, uz): главная и `plan` («Что дальше»).
Исследование и конкуренты — `docs/research/enotmebel.md`, фото — `SOURCES.md`,
заходы 21st.dev — `21ST.md`.

Главная — одна история при прокрутке по движку нашего Engelberg v2
(globalex.maximov-tech.ru/engelberg/v2): липкая сцена, слои во весь экран со
своей камерой, подписи снизу слева, глава и полоса внизу, стеклянные карточки,
точки на снимке, частицы на canvas. Главы: первый экран → «Садитесь как
удобно» (камера к груше) → «Внутри» (контур, внутренний чехол, шарики
наполнителя, наполнители на стекле) → пролёт сквозь 10 моделей → пять тканей
выезжают столбиками из настоящих образцов → офисы и логотипы заказчиков → карта доставки из Ташкента и
гарантия → финал. После истории: каталог с фильтром, подбор размера по росту,
выбор ткани и цвета по настоящим образцам (242 цвета с их карт расцветок), корпоративный заказ, гарантия, шоурум.

- `gen.mjs` собирает `out/pages.json` и `content/proto-bundles/enotmebel.json`
  (lib/proto/bundles). Ссылки — через `__PROTO_BASE__`, отпечаток ставится при
  показе зерном из `protos.stamp`.
- `intro.js` — заставка: промо DevUz Studio, затем ENOT из их логотипа: E, N,
  O слетаются, фигурка вместо «T» падает и садится; внутри букв кадр с
  креслом; камера влетает во внутренний круг «O», сквозь него открывается
  первый экран. Раз за визит, тап ведёт дальше, «Пропустить» — сразу на сайт,
  при `prefers-reduced-motion` заставки нет.
- `story.js` — история при прокрутке (время в экранах, только transform и
  opacity, без перехвата прокрутки).
- `client.js` — заказ в Telegram @enotmebel с готовым текстом, фильтр
  каталога, корзина, подбор по росту, выбор ткани и цвета, корпоративная заявка,
  параллакс шоурума, «было / стало», конструктор.
- `plan.mjs` — конструктор: сайт 1 700 $, все допы 800 $, итог 2 500 $,
  раскладка в комментарии.
- `fabrics.json` — образцы тканей (номер, размер фото, средний цвет), пишет `photos.py`.
- `logo.json` — фигурка из их логотипа (контур, сглаженный кривыми), буквы
  собраны геометрией в `gen.mjs`.
- `photos.py` — фото в `public/protos/enotmebel/`; `shots.mjs` — «было /
  стало».
- `serve.mjs` — `node serve.mjs`, затем `http://localhost:4795/proto/<43 символа>/`.
- `check.mjs` — Chromium 390×844 и 1440×900: заставка играет, пропускается
  тапом и кнопкой, без движения её нет, горизонтальной прокрутки нет, ошибок
  нет, снимки.

Перед сдачей: `node --import ./tests/alias-hook.mjs --import
./tests/tsx-hook.mjs scripts/proto-plain.mjs enotmebel` — «Чисто».

Модель прототип не вызывает: ни ProxyAPI, ни `/api/proto-ai`.
В базе — обычная запись `protos` с `facts.bundle = "enotmebel"`.
