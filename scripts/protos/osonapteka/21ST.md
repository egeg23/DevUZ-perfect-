# Блоки по мотивам 21st.dev и наших эталонов

Код каждого блока написан здесь заново, на чистом JS и CSS, без библиотек.
Движение — только transform и opacity, при «меньше движения» всё стоит.

| Блок | Откуда приём | Где в макете |
|---|---|---|
| Scroll Sequence — кадры ролика по прокрутке | наш, SamAuto и CZECHFARM | залёт в бренд на первой странице |
| Search with Suggestions (Command) — подсказки с группами | 21st.dev, Command / Search | поиск: «Лекарства» и «По действующему веществу», стрелки и Enter |
| Spotlight Card — подсветка за курсором | 21st.dev, Spotlight Card | карточки лекарств (`--mx`, `--my`) |
| Shimmer Button — блик по кнопке | 21st.dev / Magic UI | все главные кнопки (`.btn-a::after`) |
| Animated Tabs — вкладки-пилюли | 21st.dev, Animated Tabs | отпуск в каталоге, «Покупателю / Аптеке» в тарифах |
| Scroll Velocity — строка ускоряется от прокрутки | Cosmo World, Neoline | выгоды и лекарства под первым экраном |
| Sticky Scroll Reveal — телефон по шагам | 21st.dev, Sticky Scroll Reveal | «Как это работает» |
| Liquid Glass — размытие, блик рамки за пальцем | asmo, CZECHFARM, Neoline | поиск, шапка, цифры, итог тарифа и конструктора |
| Parallax Layers | наш | кварталы, метки и маршрут первого экрана |
| Pricing Toggle — тумблеры и ползунки с итогом | 21st.dev, Pricing | конструктор тарифов и «Предложение DevUz Studio» |
| Bottom Sheet | 21st.dev, Drawer | окно лекарства, бронь, «Мои брони» (на ПК — справа) |
