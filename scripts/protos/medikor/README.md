# Макет интернет-магазина Medikor (медоборудование из Кореи, Москва): исходники

Клиент DevUz: **Medikor** (medikor.ru), Москва, ул. Обручева 52с1. Задание
владельца DevUz, 15.10.2026: «По аналогии как тут (Greenwell), новый клиент…
разберись с конкурентами и тематикой, предложи вау-переходы». Магазин для
клиник, колледжей, школ и частных покупателей: счёт по ИНН, запрос КП,
документы в карточке, доставка с расчётом, панель менеджеров. Без допов по
акции 1 000 $ вместо 8 900 $, допы отдельно. Исследование —
`docs/research/medikor.md`, фото — `SOURCES.md`, снимки — `docs/screens/medikor/`.
Язык один, русский: рынок клиента — Россия.

**Знак и цвет — их**: буквы MEDIKOR гарнитурой Anton (OFL, их тяжёлый узкий
рисунок, `logo.py` → `logo.json`), «O» — их полосатый шар, рисуется кругом с
дугами; тёмно-синий знака #00082d, синий кнопок #194aaa. Шрифты — Onest для
заголовков, Inter для текста (Inter стоит и у них).

Страницы:

- `""` — страница: промо DevUz и **пульс, который входит в знак** (линия ЭКГ,
  пик в шар, «разряд» открывает первый экран, `intro.js`); магазин живьём в
  айфоне; «Сейчас / Станет» и таблица с конкурентами; **сканер по карточке
  HR-501** (луч идёт за прокруткой, подписи встают по очереди, `site.js`);
  путь закупщика в 8 шагов, каждый переключает экран магазина; счёт по ИНН
  прямо на странице; панель в окне браузера; «Стоимость» с отсчётом 48 часов
  и 17 допами тумблерами (`plan.mjs`).
- `shop` — магазин. Сначала телефон: нижняя панель (Главная, Каталог,
  Корзина, КП, Кабинет), липкая кнопка, шторки снизу; на ПК — шапка с
  поиском и телефоном, сетка в 4 колонки, карточка в две колонки.
- `panel` — панель менеджеров.

Магазин (`shop.js`, `shop.css`): главная (поиск, HR-501 с ценой у других,
«кому»: клинике, школе, колледжу, офтальмологу, спортсмену; 16 разделов),
каталог с фильтрами (цена, производитель, «с ценой / по запросу», в наличии,
со скидкой) и сортировкой, поиск с синонимами («АНД», «манекен», «вены»),
карточка (галерея, цена и наличие, у HR-501 цены других продавцов,
характеристики в таблице с прокруткой, РУ и инструкция, «В корзину», «Счёт на
организацию», «В запрос КП»; без цены — «Запросить КП»), корзина (частное
лицо или организация, город и перевозчик: самовывоз, курьер по Москве, СДЭК,
ПЭК, Деловые линии — цена по весу), оформление (ИНН → реквизиты, контакты,
оплата: картой с кодом, по QR через СБП, при получении; организации — по
счёту или картой), счёт PDF-видом, заказ (статусы до «Получен», трек,
документы: счёт, чек, УПД, гарантийный талон, РУ), запрос КП (позиции,
ИНН, «для 44-ФЗ / 223-ФЗ», срок) → ответ менеджера → «Принять» → счёт,
кабинет (организация, заказы, КП, документы, избранное). Состояние демо —
в браузере (`mk-demo-1`).

Панель (`panel.js`, `panel.css`): сводка (выручка, заказы, средний чек, ждут
оплаты по счёту, КП без ответа, доля организаций, график, что продаётся,
откуда заказы), заказы (заказ из магазина первой строкой, статус доходит до
покупателя), запросы КП (цены и сроки подставлены, скидка, отправка
покупателю), счета («Оплата поступила» запускает сборку), организации,
товары (цена, остаток, РУ), история. «Владелец / Менеджер»: менеджер не
видит выручку. Таблицы — в своей прокрутке, на телефоне второстепенные
колонки спрятаны. Действия — в `mk-panel-1`.

- `data.mjs` — факты с medikor.ru: 45 товаров из 16 разделов, цены, наличие,
  характеристики; цены HR-501 у других продавцов; `plan.mjs` — цена и допы;
- `photos.py` — их фото в WebP на белом квадрате и значки вкладки;
  `logo.py` — знак в `logo.json` (нужен `pip install fonttools` и Anton.ttf);
- `serve.mjs` — `node serve.mjs`, затем `http://localhost:4811/proto/<43 символа>/`;
  `check.mjs` — Chromium: покупка картой, по QR, счёт по ИНН, оплата из
  панели до покупателя, статус до «Получен», КП с ответом и счётом;
  все страницы на 360, 390, 428, 768, 1440 без ошибок и горизонтальной
  прокрутки; заставка закрывается сама; `screens.mjs`, `shot.mjs` — снимки.

Перед сдачей: `node --import ./tests/alias-hook.mjs --import
./tests/tsx-hook.mjs scripts/proto-plain.mjs medikor` — «Чисто».

Модель макет не вызывает. В базе — запись `protos` с `facts.bundle =
"medikor"`, `auto = false`, ниша `medoborudovanie` («Медицинское
оборудование») и ценой акции `facts.promo`: магазин 1 000 / 8 900 $.
