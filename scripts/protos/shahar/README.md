# Прототип ShahaR.Uz (shahar.uz) — исходники

Портал недвижимости по всему Узбекистану. Семь страниц на двух языках (ru,
uz): главная, `katalog`, `obekt`, `novostroyki`, `uslugi`, `podbor`
(«Подберём бесплатно»), `plan` («Что дальше»), плюс `offline`, `manifest` и
`sw` — «сайт как приложение». Исследование — `docs/research/shahar.md`, фото —
`SOURCES.md`, что взято с 21st.dev — `21ST.md`.

- `gen.mjs` собирает страницы в `out/pages.json` и сборку для сервера
  `content/proto-bundles/shahar.json` (lib/proto/bundles). Ссылки — через
  `__PROTO_BASE__`, отпечаток ставится при показе зерном из `protos.stamp`.
- `intro.js` — заставка главной: промо DevUz Studio (как на devuz.studio),
  затем «SHAHAR» крупно, город проступает в буквах, камера влетает в «H» и
  из неё открывается первый экран. Один requestAnimationFrame, раз за визит,
  тап — дальше, «Пропустить» — сразу на сайт, в режиме приложения и при
  `prefers-reduced-motion` не показывается.
- `client.js` — параллакс первого экрана и полосы новостроек, смещение шагов,
  смена слова в заголовке, счётчики, валюта $ / сум / €, избранное, фильтры
  каталога, галерея, ипотека, подбор → Telegram @operator_shahar,
  «было / стало», установка, конструктор. Только transform и opacity, без
  перехвата прокрутки.
- `plan.mjs` — конструктор: портал 1 900 $, допы с ценами и расчётом.
- `photos.py` — фото в `public/protos/shahar/`, иконки приложения.
- `serve.mjs` — `node serve.mjs`, затем `http://localhost:4791/proto/<43 символа>/`.
- `check.mjs` — Chromium 390×844 и 1440×900: заставка проигрывается и
  пропускается тапом, горизонтальной прокрутки нет, ошибок нет, снимки.

Модель прототип не вызывает: ни ProxyAPI, ни `/api/proto-ai`.
В базе — обычная запись `protos` с `facts.bundle = "shahar"`.
