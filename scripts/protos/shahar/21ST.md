# Что взято с 21st.dev и откуда

Прототип — чистые HTML/CSS/JS без React, поэтому компоненты не
скопированы, а переписаны по их устройству (только transform и opacity).
Исходники смотрели на GitHub (magicuidesign/magicui, лицензия MIT,
© Magic UI); на 21st.dev у каждого указано «License: mit».

| Компонент на 21st.dev | Автор | Где в прототипе |
|---|---|---|
| [Bento Grid](https://21st.dev/@dillionverma/components/bento-grid) | Dillion Verma (Magic UI), MIT | главная, «Не только лента объявлений»: иконка уходит вверх, «Подробнее» выезжает при наведении |
| [Marquee](https://21st.dev/@dillionverma/components/marquee) | Dillion Verma (Magic UI), MIT | две встречные бегущие строки: районы Ташкента и 16 типов объектов, пауза при наведении |
| [Number Ticker](https://21st.dev/@dillionverma/components/number-ticker) | Dillion Verma (Magic UI), MIT | цифры 1998 · 13 · 16 катятся при появлении |
| [Border Beam](https://21st.dev/@dillionverma/components/border-beam) | Dillion Verma (Magic UI), MIT | луч по кромке карточки «Подберём бесплатно» — вращением конического градиента, а не offset-distance |
| [Word Rotate](https://21st.dev/@dillionverma/components/word-rotate) | Dillion Verma (Magic UI), MIT | «Найдите квартиру / дом / дачу / офис / участок / чайхону» в заголовке |
