# Макет главной vTashkente (vtashkente.uz) — исходники

Авторские кухни на заказ в Ташкенте. Задача владельца, 16.10.2026: «Используй
ароматы из предыдущих макетов, докрути и подумай. Делаем только главную
страницу с Хиро секциями на презентацию». Одна страница на двух языках (ru,
uz) из полноэкранных секций, у каждой свой приём. Что на их сайте мешает
заказать — `docs/research/vtashkente.md`, откуда снимки — `SOURCES.md`.

| Секция | Приём | Откуда приём |
|---|---|---|
| Заставка | промо DevUz Studio, затем их знак: оранжевый круг, белая галочка V прочерчивается, круг летит на зрителя и открывает первый экран | arhbyuro, enotmebel |
| Первый экран | четыре их кухни сменяют друг друга во весь экран с медленным наездом, в оранжевой плашке перебираются их слова «Проектируем, Рисуем, Производим, Доставляем, Устанавливаем» | их сайт, sia |
| Сборка | угловая кухня собирается по прокрутке на canvas: чертёж стен с размерами, цоколь и корпуса, фасады подъезжают, столешница ложится, техника встаёт, в комнате темнеет и загорается подсветка | сборка здания pkvesta |
| Примерка | их кухня Сантьяго VIP: цвет фасадов и столешницы ложится умножением на снимок, тени и блики остаются с фото; каждый цвет взят с их же кухни (Лондон, Ницца, Нью-Йорк, Амстердам, Мельбурн) | конструкторы invis, greenwell |
| Работы | восемь кухонь большими кадрами едут вбок от прокрутки, у кухонь с видеообзором ссылка на YouTube | sia |
| Как заказать | их пять шагов до чаепития, бегущая строка от скорости прокрутки, расчёт погонных метров по планировке с отправкой размеров в их Telegram | sia, enotmebel |
| Производство и шоу-рум | два снимка во весь экран с параллаксом, их цифры, восемь видеообзоров | enotmebel |
| Стоимость | предложение 48 часов: лендинг 500 $ вместо 1 700 $, корпоративный 1 000 $ вместо 2 500 $ (`PROMO`, `lib/admin/mockup-offer.ts`) | общее правило |
| Заявка на замер | форма справа на фоне образцов из шоу-рума и та же форма панелью справа с любой кнопки; в макете никуда не уходит, это сказано на экране, текст можно отправить в их Telegram | arhbyuro |

Шапка прячется при прокрутке и возвращается через 3 секунды, меню во весь
экран с фоном у каждого пункта (arhbyuro). На телефоне главное действие
внизу экрана. Скролл не перехватывается, всё на `transform` и `opacity`,
при `prefers-reduced-motion` заставки нет, сборка стоит готовой, лента
работ листается пальцем.

Цен и сроков на их сайте нет («Почему нет цен на сайте?»), поэтому расчёт
считает метры, а не сумму, и отправляет размеры в их Telegram. Когда они
назовут цену за метр, она встанет одной строкой.

## Файлы

- `gen.mjs` — тексты ru/uz и разметка, собирает `out/pages.json` и
  `content/proto-bundles/vtashkente.json` (lib/proto/bundles). Ссылки через
  `__PROTO_BASE__`, отпечаток ставится при показе зерном из `protos.stamp`.
- `style.css`, `intro.js`, `assembly.js` (сборка кухни), `site.js` (всё
  остальное).
- `photos.py` — их снимки в `public/protos/vtashkente` (WebP), плитка дуба
  для примерки, значки вкладки: `python3 -I photos.py <папка с файлами>`.
- `serve.mjs` — `node serve.mjs`, затем `http://localhost:4821/proto/<43 символа>/`.
- `check.mjs` — Chromium 390×844, 1440×900, 1920×1080: заставка, без
  горизонтальной прокрутки, без ошибок, примерка, расчёт, заявка, панель,
  шапка, версия без движения; снимки. `node check.mjs <папка> [ru|uz]`.

Снимки для PR — `docs/screens/vtashkente/`.

Перед сдачей: `node --import ./tests/alias-hook.mjs --import
./tests/tsx-hook.mjs scripts/proto-plain.mjs vtashkente` — «Чисто».

Модель макет не вызывает. В базе — запись `protos` с `facts.bundle =
"vtashkente"`, ниша `mebel`, `auto = false`.
