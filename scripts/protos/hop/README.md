# Прототип HOP.UZ (hop.uz) — исходники

Доска бесплатных объявлений по всему Узбекистану: 14 категорий, 13 городов,
безопасная сделка, аукционы, бизнес-тарифы. Пять страниц на русском:
главная, `razmestit`, `sdelka`, `biznes`, `plan` («Что дальше»). Каркас —
ПК Веста и Aipply Academy (`scripts/protos/pkvesta`, `scripts/protos/aipply`):
шапка, промо DevUz, конструктор, «было / стало». Сцена при прокрутке — по
движку Engelberg v2. Исследование — `docs/research/hop.md`, снимки —
`SOURCES.md`, заходы 21st.dev — `21ST.md`.

- `gen.mjs` собирает `out/pages.json` и `content/proto-bundles/hop.json`.
- `intro.js` — промо DevUz Studio, буквы HOP! слетаются, камера влетает во
  внутренний круг «O»: круг — дыра в заставке, сквозь неё виден первый экран.
- `story.js` — «Как вещь находит покупателя»: липкая сцена, телефон продавца,
  лента с поиском, чат, безопасная сделка, аукцион, отзыв, всё кодом.
- `client.js` — параллакс и стекло первого экрана, подсказки поиска по
  каталогу, живой аукцион, мастер объявления в Telegram HOP.UZ, колесо
  фортуны, витрина без конкурентов, конструктор.
- `plan.mjs` — сайт 4 500 $, все допы 3 500 $, итог 8 000 $.
- `catalog.json` — меню hop.uz: адрес и название каждого раздела;
  `cats.json` — 14 категорий и их разделы; `qr.txt` — QR на их APK.
- `photos.py` — значки вкладки и «было / стало»; `shots.mjs` — снимки.
- `serve.mjs` — локальный показ: `node serve.mjs`, затем
  http://localhost:4794/proto/<43 символа>/

Перед сдачей: `node --import ./tests/alias-hook.mjs --import
./tests/tsx-hook.mjs scripts/proto-plain.mjs hop` — должно быть «Чисто».
