# Макет сайта ресторана Karomat (Ташкент, Фозилтепа 10А): исходники

Клиент DevUz: **Karomat Restaurant** — https://www.karomat-restaurant.uz, семейный
ресторан и той-зал узбекской, турецкой и уйгурской кухни. Задание владельца DevUz,
16.10.2026: «Прототип по karomat-restaurant.uz… используй наш стандартный промпт с
анализом конкурентов, анимациями и т. д.». Исследование — `docs/research/karomat.md`,
фото — `SOURCES.md`, снимки — `docs/screens/karomat/`.

Главный язык — **узбекский**, как у них на сайте: `""`, `menu`, `panel`; русский —
`ru`, `ru/menu`, `ru/panel`.

## Что внутри

Главная (`site.css`, `site.js`, `intro.js`):

| Блок | Движение |
|---|---|
| Заставка | промо DevUz, затем их золотой знак: круг вырастает, кольцо прочерчивается, буквы KAROMAT встают, кольцо становится проёмом в первый экран |
| Первый экран | тёмный стол, как фон их съёмки; по прокрутке с краёв прилетают и садятся девять их блюд, над шурпой пар (canvas), в конце «Stolingiz kutmoqda». Сцена стоит на sticky, GSAP ScrollTrigger только читает положение |
| Бегущая строка | названия их блюд, скорость от прокрутки |
| Сейчас и станет | пять находок на их сайте, строка «переворачивается» |
| Меню | 127 блюд из их API: разделы, фильтры, тарелки «падают» на место |
| Заказ в айфоне | 8 шагов, каждый переключает экран приложения |
| Бронь | дата, время, гости, стол на схеме зала; бронь сразу в панели |
| Банкет и той | стол на 10 гостей из их блюд, итог с обслуживанием 15%, заявка в панель |
| QR-меню | карточка стола 7 и айфон в режиме стола: официант и счёт |
| Видео | их Shorts рядом с блюдами из роликов |
| Отзывы | Яндекс Карты: 4,5, 863 оценки, 146 отзывов |
| Что взяли у соседей и у лучших, панель в окне, стоимость с допами и отсчётом 48 часов | |

Приложение гостя (`app.js`, `app.css`): меню с поиском на двух языках, карточка
с порциями, корзина с подсказками, оформление в один экран (доставка, самовывоз
или на стол по QR, код 1234, Click / Payme / Uzum / наличные), оплата с кодом,
статус, бронь на схеме, банкет, кабинет с баллами 5%. В режиме стола (`#/t/7`)
полоса с «Официант» и «Счёт».

Панель (`panel.js`, `panel.css`): сводка, заказы со статусами, брони по столам и
часам, банкеты по этапам, зал и вызовы по QR, меню со стоп-листом, популярные
блюда. «Владелец / Менеджер»: менеджер не видит выручку.

Демо-состояние — в браузере (`km-demo-1`): одно на главную, приложение и панель,
поэтому бронь с главной видна в панели, статус из панели — у гостя, стоп-лист —
в приложении.

## Файлы

- `menu-src.json` — их меню из API (16.10.2026); `data.mjs` — бренд, меню с
  узбекскими названиями, стол первого экрана, отзывы, Shorts, схема зала (пример),
  банкетный стол; `ui.mjs` — подписи [ru, uz]; `plan.mjs` — цена и допы;
- `photos.py` — их фото из `src/` в WebP (`src/` — выгрузка с сайта и YouTube,
  70 МБ, в репозиторий не кладём: готовые WebP в `public/protos/karomat`);
- `gen.mjs` → `content/proto-bundles/karomat.json`;
- `serve.mjs` — `node serve.mjs`, затем `http://localhost:4814/proto/<43 символа>/`;
  `check.mjs` — Chromium: страницы на 360-1440 без ошибок и прокрутки вбок, шапка
  по правилу трёх секунд, весь путь гостя на 390 (uz, ru), без движения;
  `shots.mjs` — снимки в `docs/screens/karomat`.

GSAP 3.13 и ScrollTrigger лежат у нас (`public/protos/karomat/`): со стороны
макет грузит только шрифты Google (Prata, Onest).

Перед сдачей: `node --import ./tests/alias-hook.mjs --import ./tests/tsx-hook.mjs
scripts/proto-plain.mjs karomat` — «Чисто».

Модель макет не вызывает. В базе — запись `protos` с `facts.bundle = "karomat"`,
`auto = false`, ниша `restoran` и ценой акции `facts.promo`: сайт 1 000 / 2 500 $.
