# Прототип Asmo Clinic (asmoclinic.uz) — исходники

Частная дерматологическая клиника в Ташкенте, Мирабадский район, с 2021 года.
Две страницы на двух языках (ru, uz): главная и `plan` («Что дальше»).
Собран на движке LIDER PROF PROEKT (`scripts/protos/lider-prof`): промо
DevUz, сцена при прокрутке по Engelberg v2, жидкое стекло, конструктор цены,
«было / стало». Исследование и конкуренты — `docs/research/asmo.md`,
источники — `SOURCES.md`, заходы 21st.dev — `21ST.md`.

- `gen.mjs` собирает `out/pages.json` и `content/proto-bundles/asmo.json`
  (lib/proto/bundles). Ссылки — через `__PROTO_BASE__`, отпечаток ставится
  при показе зерном из `protos.stamp`.
- `logo.mjs` + `logo.json` — их логотип из `logo-dark.svg`: двенадцать
  кругов знака геометрией, буквы их контурами. Один символ на страницу.
- `art.mjs` — рисунки кодом: кожа сверху (родинка, папиллома, борозды),
  разрез кожи по слоям, клетки первого экрана, пузырьки озона.
- `intro.js` — промо DevUz Studio, точки знака слетаются, проявляются буквы,
  камера влетает в центральный голубой круг, он становится просветом на
  первый экран. Раз за визит, тап ведёт дальше, «Пропустить» — сразу на сайт.
- `story.js` — история вглубь кожи: клетки и цифры → линза дерматоскопа по
  коже (родинка, папиллома) → разрез кожи с метками лечения → свет, лучи и
  озон → четыре этапа → специалисты по орбите → запись.
- `client.js` — смена цвета страницы между блоками (только opacity слоёв),
  бенто, онлайн-запись (направление, день, время → Telegram @asmo_clinic),
  конструктор лечения в сумах, тест «к кому записаться», цитата по прокрутке,
  конструктор сайта.
- `prices.mjs` — цены конструктора лечения: середина рынка Ташкента (на сайте
  клиники цен нет), подписаны на странице как ориентир.
- `plan.mjs` — сайт 1 700 $, допы на макете 670 $, сверх сайта 630 $, итог
  3 000 $.
- `shots.mjs` — «было / стало» и значки вкладки; `serve.mjs` — `node
  serve.mjs`, затем `http://localhost:4801/proto/<43 символа>/`;
  `check.mjs` — Chromium 390×844 и 1440×900.

Перед сдачей: `node --import ./tests/alias-hook.mjs --import
./tests/tsx-hook.mjs scripts/proto-plain.mjs asmo` — «Чисто».

Модель прототип не вызывает: ни ProxyAPI, ни `/api/proto-ai`.
В базе — запись `protos` с `facts.bundle = "asmo"`, `auto = false`.
