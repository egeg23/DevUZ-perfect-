# Заходы 21st.dev в прототипе Asmo Clinic

Брали только компоненты под MIT. Код каждого захода свой, на чистом CSS и
JS, без React и библиотек: прототип — страница без сборки. Aceternity и
React Bits не берём (закрытая лицензия и Commons Clause).

| Блок | Заход | Автор на 21st.dev | Где в коде |
|---|---|---|---|
| Услуги | Bento Grid: сетка карточек разного размера | dillionverma (Magic UI) | `.bento`, `style.css` |
| Карточки услуг | Magic Card: пятно света за курсором | dillionverma (Magic UI) | `.spot-host`, `client.js` |
| Специалисты в истории | Orbiting Circles: значки по двум орбитам | dillionverma (Magic UI) | `.orbit`, `story.js` |
| Цитата | Text Reveal: слова загораются по прокрутке | dillionverma (Magic UI) | `#qt`, `client.js` |
| Кнопки записи | Shimmer Button: блик по кнопке | dillionverma (Magic UI) | `.shim` |
| Итог конструктора лечения | Border Beam: луч по рамке | dillionverma (Magic UI) | `.prc-tot::before` |
| Цифры клиники, итог в сумах | Number Ticker: числа набегают | dillionverma (Magic UI) | `count()`, `tick()` |

Своё: заставка с влётом в голубой круг знака, линза дерматоскопа с
увеличенной копией кожи (два встречных transform), разрез кожи с камерой по
слоям, лучи и пузырьки физиотерапии, жидкое стекло с преломлением (`#lq`),
смена цвета страницы слоями, движения появления «клетка», «линза», «капля»,
«волос».
