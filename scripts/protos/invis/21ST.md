# Заходы 21st.dev в макете Invis

Брали только компоненты под MIT (лицензии проверены, исследование, раздел 7).
Код каждого захода свой, на чистом CSS и JS, без React: макет — страница без
сборки. Aceternity (своя закрытая лицензия), React Bits (MIT + Commons Clause)
и «liquid glass» / spotlight-карточки без лицензии на 21st.dev не берём:
жидкое стекло своё (`.glass.lq`, преломление `#lq`).

| Блок | Заход | Автор на 21st.dev | Где в коде |
|---|---|---|---|
| Хуки под первым экраном | Marquee: бегущая строка, пауза при наведении | dillionverma (Magic UI) | `.mq`, `site.css` |
| «Забронировать место», «Кабинет во весь экран» | Shimmer Button: блик по кнопке | dillionverma (Magic UI) | `.shim` |
| Итог конструктора | Border Beam: луч по рамке | dillionverma (Magic UI) | `.beam` |
| «Зал сейчас», итог конструктора | Number Ticker: числа набегают | dillionverma (Magic UI) | `roll()`, `calc()`, `site.js` |
| Карточки зон | Magic Card: пятно света за курсором | dillionverma (Magic UI) | `.spot` |
| Карточки зон | Tilt: наклон за курсором | ibelick (Motion Primitives) | `.tilt`, `site.js` |

Своё: влёт камеры в прицел знака Invis (просвет evenodd на canvas), сцена
«Сетап» по прокрутке (только transform и opacity), параллакс фото и
видеокарты, неоновый пол, честное колесо, живая карта зала, кабинеты.
