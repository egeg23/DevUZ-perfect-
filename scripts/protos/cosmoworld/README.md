# Макет Cosmo World (cosmoworld.uz): премиум, пролёт камеры по прокрутке

Задача владельца DevUz, 28.10.2026: премиум-макет дистрибьютора косметики и
бытовой химии со сценой по прокрутке. Рецепт — `.claude/skills/proto-master/premium.md`
(эталон SamAuto), разведка и раскадровка — `docs/research/cosmoworld.md`.

**Факты — только с их сайтов** (`data.mjs`): cosmoworld.uz, /en и cosmo.kg.
Цен у них нет, в макете тоже. Языки — RU, UZ (латиница), EN.

## Состояние

1. Разведка, факты, структура разделов — готово.
2. Референс первого экрана — ждёт выбора владельца (три варианта).
3. Ключевые кадры 4K и раскадровка картинками — после выбора.
4. Переходы Kling, сцена, сайт, шифр, проверки — после «да» на раскадровку.
