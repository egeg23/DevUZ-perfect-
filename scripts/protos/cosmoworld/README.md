# Макет Cosmo World (cosmoworld.uz): премиум, пролёт камеры по прокрутке

Задача владельца DevUz, 28.10.2026: премиум-макет дистрибьютора косметики и
бытовой химии со сценой по прокрутке. Рецепт — `.claude/skills/proto-master/premium.md`
(эталон SamAuto), разведка, раскадровка и номера генераций —
`docs/research/cosmoworld.md`. Снимки — `docs/screens/cosmoworld/`.

**Факты — только с их сайтов** (`data.mjs`): cosmoworld.uz, /en и cosmo.kg.
Цен у них нет, в макете тоже. Языки — RU, UZ (латиница), EN. Формы ничего
не отправляют: собирают текст и открывают их WhatsApp (Telegram — текст
копируется).

Стиль: сцена ночная, как одобренный кадр (Revolut-реклама, которую дал
владелец); дальше их минимализм — светлый `#edf8ff`, тёмно-синий `#052659`,
голубой `#67adfc` — и «ледяное стекло» подиума как сквозной приём: у карточек
снизу голубое свечение, блик идёт за курсором. Шрифты их: Play и Manrope.
Шапка прячется при прокрутке и возвращается через 3 с; на телефоне главная
кнопка внизу под большим пальцем.

## Сцена

Ключевые кадры — nano banana 2.1, 4K (16:9 и 9:16 отдельно), переходы —
Kling 3.0 pro, 6 с, без звука (владелец, 28.10.2026: «Видео переходы не
делай сильно замудрёными»; 4K вышел бы втрое дороже бюджета). Компьютер
листает 118 кадров трёх переходов, у ключевых кадров камера стоит, соседние
кадры смешиваются; распакованных в памяти не больше 12. Телефон — четыре
ключевых кадра 9:16 со сменой и наездом. Reduced motion, экономия трафика,
нет WebCrypto — обложка и первая подпись.

Кадры в `public/protos/cosmoworld/seq` — только шифром (AES-256-GCM, 12 байт
nonce + шифр), ключ `SCENE_KEY_COSMOWORLD` в хранилище секретов, отдаёт его
`app/proto/[token]/promo/scene` (`SCENES` в `lib/proto/promo.ts`).

## Пересборка

```
SCENE_KEY=<64 hex> python3 -I scene.py <папка с t1-3.mp4, d1.png, d3.png, m1-4.png>
python3 -I pics.py <папка со снимками брендов>
rb/bin/python -I cut.py <та же папка, вырезки Higgsfield в hf/>
node logos.mjs <папка с логотипами брендов>
python3 -I map.py <uz.geojson>
node gen.mjs
SCENE_KEY=<64 hex> node serve.mjs   # http://localhost:4832/proto/<43 символа>/
node shots.mjs 390,1440 ru,uz,en
```

Проверка: `proto-plain cosmoworld` — «Чисто», `npm test`
(`tests/proto-bundles.test.ts`, «Cosmo World…»), `npx tsc --noEmit`.
