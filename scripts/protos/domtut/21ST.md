# Заходы 21st.dev в макете DomTut

Брали только компоненты под MIT. Код каждого захода свой, на чистом CSS и JS,
без React: макет — страница без сборки. Aceternity и React Bits не берём
(закрытая лицензия и Commons Clause).

| Блок | Заход | Автор на 21st.dev | Где в коде |
|---|---|---|---|
| «Больше, чем лента объявлений» | Bento Grid: карточки разного размера | dillionverma (Magic UI) | `.bento`, `site.css` |
| Карточки бенто | Magic Card: пятно света за курсором | dillionverma (Magic UI) | `.spot`, `site.js` |
| Районы Ташкента | Marquee: бегущая строка, пауза при наведении | dillionverma (Magic UI) | `.mq` |
| Кнопки «Найти», «Во весь экран» | Shimmer Button: блик по кнопке | dillionverma (Magic UI) | `.shim` |
| Итог конструктора | Border Beam: луч по рамке | dillionverma (Magic UI) | `.beam` |
| Счётчики первого экрана, итог | Number Ticker: числа набегают | dillionverma (Magic UI) | `count()`, `roll()` |

Своё: влёт камеры в сердце их знака (просвет по форме сердца, evenodd на
canvas), путь покупателя (телефон стоит, экран меняется по шагу), параллакс
фото и рендеров внутри карточек, жидкое стекло с преломлением (`#lq`),
приложение в айфоне с переходами как в iOS, свайпом назад и нижними листами.
