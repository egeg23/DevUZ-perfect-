# Прототип Shox International Hospital — исходники

Две страницы на трёх языках (ru, uz, en): главная и «Что дальше» (конструктор).
Исследование — `docs/research/clinic-shox.md`.

## Что есть на главной

- **3D-пролёт по врачам.**
  - Sticky-секция, камера идёт за позицией прокрутки. Прокрутку скрипт не
    перехватывает: ни слушателя `scroll`, ни `scrollTo`.
  - На кадр меняются только `transform` у сцены и `opacity` у карточек.
  - Кадры считаются, только пока секция на экране (IntersectionObserver).
  - При `prefers-reduced-motion` и без 3D пролёта нет — вместо него сетка.
- **Направления** — бенто-сетка.
- **Роботохирургия** с параллаксом.
- **Врачи** — фильтр по направлению и поиск.
- **Запись в 3 шага.** Расписание в прототипе — пример. Заявка копируется в
  буфер обмена, затем открывается бот клиники.
- **Прейскурант** с поиском и рубриками.
- **Блоки-допы:** чек-ап, отзывы, иностранным пациентам.
- **Филиалы** — схема со ссылками в Яндекс Карты.
- **Мессенджеры.**
- **«5 секунд на скидку 10 %».**
  - Механика «Минуты на скидку» с devuz.studio (`lib/minute-client.ts`): окно
    одно на браузер, успели — код закреплён в localStorage и виден в форме
    записи, не успели — больше не предлагается.
  - В прототипе сервера нет, поэтому код ставит браузер.
  - Повторить таймер можно кнопкой в конструкторе.

## Файлы

| Файл | Что в нём |
|---|---|
| `data.mjs` | Факты с shox.hospital: врачи, направления, филиалы, роботохирургия |
| `plan.mjs` | Конструктор: база 1 500 $, допы и как посчитаны цены |
| `gen.mjs` | Сборка: `out/pages.json` (локально) и `content/proto-bundles/shox-hospital.json` (сервер) |
| `photos.cjs` | Обработка фото: `node photos.cjs <исходники> public/clients/shox-hospital` |
| `serve.mjs` | Локальный показ: `node serve.mjs`, затем `http://localhost:4790/proto/<43 символа>/` |
| `check.mjs` | Проверка в Chromium: горизонтальная прокрутка, ошибки, запись, прейскурант, скидка, снимки |
| `SOURCES.md` | Что взято с 21st.dev и откуда |

Фото врачей лежат в `public/clients/shox-hospital/` и отдаются с
`X-Robots-Tag: noindex` (`next.config.ts`).

## В базе

Обычная запись `protos` с `facts.bundle = "shox-hospital"`. Страницы отдаёт
`lib/proto/bundles`. Отпечаток ставится зерном из `protos.stamp`, условия
`/{язык}/mockup-terms` стоят в подвале каждой страницы, журнал показа ведёт
`lib/proto/serve`.

Вызовов модели в прототипе нет: ни `/api/proto-ai`, ни ProxyAPI.
