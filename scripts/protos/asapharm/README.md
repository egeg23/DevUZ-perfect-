# Макет ASAPHARM Academy (asapharmacademy.uz) — исходники

«Школа регистратора» в Ташкенте: учебный центр по регистрации лекарственных
средств. Задание владельца 20.11.2026: продающий макет, курсы (базовый,
продвинутый, онлайн), преподаватели, отзывы, сертификаты, FAQ, заявка;
ru и uz; лендинг 500 $, допы не дороже 1 500 $; Higgsfield до 10% баланса.
Снимок «до» — `BEFORE.md`, разведка и awwwards — `docs/research/asapharm.md`.

Страницы: `""` (ru), `uz`, `panel`, `uz/panel`.

- `data.mjs` — всё об академии, только с их сайта; узбекский — наш перевод.
- `gen.mjs` — собирает `out/pages.json` и `content/proto-bundles/asapharm.json`.
  Видео DevUz — `dzIntroSolo` первой строкой. Ловушки: имя в образце
  сертификата (`[[t:0]] [[t:1]]`) и два демо-имени в панели (`[[t:2]]`,
  `[[t:3]]`); числа скрипта с меткой — дрейф и длина связей молекул,
  разброс источников в панели.
- `style.css`, `site.js` — лендинг: шапка прячется при прокрутке и
  возвращается через 3 с, молекулы на холсте, отсчёт до старта потока,
  «Путь досье» (липкая сцена, высота `--vh1` в пикселях от первой высоты
  окна), подбор курса в 3 вопроса, вебинары с отсчётом, проверка
  сертификата, отзывы лентой, заявка в браузер и в Telegram администратора
  (`@a_zakirova` с их сайта), конструктор с акцией 48 часов.
- `panel.css`, `panel.js`, `ui.mjs` — панель по эталону Greenwell, вид
  Glassy V2: вход кодом (любые 4 цифры), сводка, заявки с сайта первой
  строкой со статусом, который видит слушатель, места в потоках, вебинары,
  роли (менеджер не видит источники), история.
- `plan.mjs` — лендинг 500 $ вместо 1 700 $, девять допов на 1 500 $.
- `serve.mjs` — `node serve.mjs`, затем http://localhost:4797/proto/<43 символа>/

Перед сдачей: `node --import ./tests/alias-hook.mjs --import
./tests/tsx-hook.mjs scripts/proto-plain.mjs asapharm` — «Чисто».
