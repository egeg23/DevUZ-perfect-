# Блоки по мотивам 21st.dev и наших эталонов

Код каждого блока написан здесь заново, на чистом JS и CSS, без библиотек.
Движение — только transform и opacity, при «меньше движения» всё стоит.

| Блок | Откуда приём | Где в макете |
|---|---|---|
| Scroll Sequence — кадры по прокрутке | наш, SamAuto и Oson Apteka | залёт в глобус-знак на первой странице |
| Animated Beam / Route Lines — линии между точками | 21st.dev, Animated Beam; маршруты Apollo Travel и Global Export | дуги на первом экране, «Маршруты», «Склады» |
| Sticky Scroll Reveal — сцена стоит, шаги меняются | 21st.dev, Sticky Scroll Reveal | «Маршруты»: камера идёт по пяти направлениям, карточка меняется |
| Spotlight Card — подсветка за курсором | 21st.dev, Spotlight Card | карточки услуг (`--mx`, `--my`) |
| Shimmer Button — блик по кнопке | 21st.dev / Magic UI | все главные кнопки (`.btn-a::after`) |
| Animated Tabs — вкладки-пилюли | 21st.dev, Animated Tabs | вид транспорта, валюта итога |
| Scroll Velocity — строка ускоряется от прокрутки | Cosmo World, Neoline, Oson Apteka | услуги и партнёры под первым экраном |
| Marquee — бесконечная лента, стоп при наведении | 21st.dev, Marquee | авиакомпании-партнёры |
| Liquid Glass — размытие, блик рамки за пальцем | asmo, CZECHFARM, Neoline | шапка, быстрый расчёт, цифры, итог конструктора, контакты |
| Parallax Layers | наш | кадр грузового узла и дуги первого экрана |
| Pricing Toggle — тумблеры и ползунки с итогом | 21st.dev, Pricing | конструктор тарифов и «Предложение DevUz Studio» |
| Timeline / Stepper | 21st.dev, Timeline | отслеживание груза по номеру |
| Bottom Sheet | 21st.dev, Drawer | заявка и «Мои заявки» (на ПК — справа) |
| Kanban / Drag and Drop | 21st.dev, Kanban | диспетчерская: очередь грузов и машины, перенос груза пальцем или мышью |
| Progress Bars | 21st.dev, Progress | загрузка машины в кг и м³, красная при перегрузе |
| Live Map Markers | наш, Apollo Travel и Global Export | водители на схеме с пульсом статуса |
| Segmented Control | 21st.dev, Segmented Control | «По рейтингу / По цене» в выборе перевозчика |
