# Макет главной Soffice (soffice.uz): исходники

Soffice — управляющий партнёр бизнес-центров Ташкента (Global Property Group):
офисы, кабинеты, опенспейс, коворкинг в 18 БЦ, без комиссий. Задача владельца
DevUz, 19.10.2026: «новый клиент, хотят посмотреть на макет главной». Макет
покажут на большом экране на встрече, поэтому 1440 так же важен, как 390.
Исследование — `docs/research/soffice.md`, фото — `SOURCES.md`, снимки —
`docs/screens/soffice/`.

Одна страница на трёх языках: ru (`""`), uz (`uz`, латиница, ни одной
кириллической буквы — держит тест), en (`en`, у них иностранные арендаторы).

| Блок | Что делает |
|---|---|
| Видео DevUz | `dzIntroSolo`, поверх страницы, потом сразу сайт |
| Первый экран | их башни во весь экран с медленным наездом; «Офис в Nest One»: имя башни меняется вместе с кадром; подбор «площадь → район или БЦ → бюджет в месяц» с живым «подходят N бизнес-центров, от X млн в месяц» и 18 точками |
| Арендаторы | бегущая строка 18 логотипов с их сайта, «без комиссий» |
| Карта | своя SVG-схема Ташкента: три линии метро, станции со страниц БЦ, районы, 18 точек по классу; точка — карточка с фото, суммой в месяц за вашу площадь, метро, парковкой |
| Каталог | 18 карточек с их фото, фильтры района и формата, «только по площади и бюджету», сортировка, сравнение до трёх, «На просмотр», ссылка на страницу БЦ у них |
| Сколько в месяц | БЦ × площадь: в месяц, с НДС 12% и без, за год; переключатель «ставка указана без НДС / с НДС», потому что у них это не сказано |
| Схема этажа | Platform, 3 и 4 этаж, свободные блоки оранжевым (механика invis), блок — сумма и запись на этот блок; планировка условная, сказано на экране |
| Просмотр | день и время — и готовое сообщение: WhatsApp с текстом, Telegram менеджера (текст копируется), звонок |
| Доверие | их цифры, пять отзывов с фото, частые вопросы |
| Сейчас и станет | семь находок по их сайту словами арендатора; шесть механик лучших сайтов аренды |
| Стоимость | 1 000 $ вместо 2 500 $ на 48 часов, 11 допов тумблерами (`plan.mjs`), отсчёт |

Шапка прячется при любой прокрутке и возвращается через 3 секунды; на
телефоне внизу всегда «Подобрать офис», звонок, WhatsApp, Telegram. Скролл не
перехватывается: GSAP ScrollTrigger только двигает фото (`transform`), всё
остальное — классы на `transform`/`opacity`. При `prefers-reduced-motion`
кадр первого экрана стоит, всё видно сразу. Тяжёлого до первого экрана нет:
первое фото с `fetchpriority`, остальное `loading="lazy"`, GSAP с `defer`.

## Файлы

- `data.mjs` — 18 БЦ, метро, логотипы, отзывы, «сейчас и станет», механики,
  вопросы; `plan.mjs` — цена и допы;
- `style.css`, `site.js` — комментарии вырезает сборка, в разметку клиенту
  они не попадают;
- `gen.mjs` → `out/pages.json` и `content/proto-bundles/soffice.json`;
- `photos.py` — их фото в WebP: `python3 -I photos.py <папка выгрузки>`;
- `serve.mjs` — `node serve.mjs`, затем `http://localhost:4823/proto/<43 символа>/`;
- `check.mjs` — Chromium: ru, uz, en на 360-1440, видео, шапка, подбор,
  карта, каталог, сравнение, калькулятор, этаж, просмотр, стоимость, кадры
  при прокрутке на медленном телефоне, версия без движения;
- `shots.mjs` — снимки в `docs/screens/soffice`.

Перед сдачей: `node --import ./tests/alias-hook.mjs --import ./tests/tsx-hook.mjs
scripts/proto-plain.mjs soffice` — «Чисто».

Модель макет не вызывает, Higgsfield не использовали. В базе — запись `protos`
с `facts.bundle = "soffice"`, ниша `nedvizhimost`, `auto = false`, цена акции
`facts.promo`: 1 000 / 2 500 $.
