# Откуда фото и тексты макета Soffice

Всё — с soffice.uz, снято 19.10.2026 (curl, user agent `devuz-check-bot`).
Выгрузку в репозиторий не кладём; готовые WebP — `public/protos/soffice`,
собирает `photos.py`.

| Файл | Откуда |
|---|---|
| `h-<бц>-{1600,900,m}.webp` | первый кадр страниц Nest One, Trilliant, Forum, Sapphire (`soffice.uz/<бц>`) |
| `b-<бц>-{960,560}.webp` | первый кадр страницы каждого из 18 БЦ, у Kayan — их зал переговоров, у Panoramic — кадр 1000 px |
| `i-open-*`, `i-lobby-*`, `i-cab-*`, `i-meet-*` | интерьеры с главной soffice.uz (блок «Аренда в бизнес-центрах») |
| `r-<имя>.webp` | фото авторов отзывов с главной |
| `l-01…l-18.webp` | логотипы арендаторов из бегущей строки главной, как у них |
| `logo.webp`, `icon-192.png`, `apple-180.png` | их логотип и значок вкладки |
| `gsap.min.js`, `ScrollTrigger.min.js` | GSAP 3.13, как в tovar |

Тексты: классы, адреса, метро, площади, парковки, ставки «от … сум/м²»,
состав ставки, отзывы, вопросы, цифры (1000+, 220 000 м², 2020), контакты —
со страниц soffice.uz. Переводы отзывов на узбекский и английский — наши.
Координаты на карте — примерные, по адресу и станции метро.
