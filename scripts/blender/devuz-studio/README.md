# Ролик «Вечерняя студия DevUz»

3D-сцена в Blender, собранная только кодом: геометрия, материалы на узлах,
свет, камера, анимация, пылинки и логотип. Руками в интерфейсе Blender
ничего не делается — всё воспроизводится одной командой.

**Раскадровка** (30 к/с, 420 кадров, 14 с):

| Время      | Что в кадре |
|------------|-------------|
| 0–6,5 с    | пролёт по офису между столами: мониторы, на экранах «печатают» код, лампы, книги, растения, кофе, неон «DevUz Studio» на кирпиче, пылинки в закатных лучах |
| 6,5–9 с    | разворот к окнам, пролёт сквозь открытую створку; за окном — закатный город с бирюзовыми куполами и телебашней |
| 9–12 с     | разгон к солнцу: угол шире, размытие движения, свечение нарастает до белого |
| 12–14 с    | из белого проявляется объёмный знак DevUz и подпись devuz.studio |

## Файлы

- `scene.py` — вся сцена и рендер (`blender -b -P scene.py -- …`).
- `screens.py` — кадры экранов (тёмный редактор с подсветкой, номерами
  строк и курсором; код набирается по знаку за кадр) и надписи шрифтом
  сайта. Обычный Python с Pillow, запускается до Blender.
- `snippets.py` — код на экранах: TypeScript и Python, написан для ролика,
  без секретов и чужих логотипов.

Логотип читается из `public/brand/logo-square-alpha.svg`: звезда, прорези
`<` `>` (штрихи маски с круглыми концами) и золотая черта — по координатам
файла, градиент — по его `linearGradient`. Знак выдавлен на 20 см с
фаской, форма не искажается. Шрифты — сайта: `app/fonts/jetbrains-mono.woff2`
на экранах, `app/fonts/unbounded.woff2` в неоне и подписи (вариативный
шрифт Blender рисует с дырами в буквах, поэтому надписи — картинками из
Pillow).

## Blender

Blender **4.5.14 LTS**, Linux x64:
https://download.blender.org/release/Blender4.5/blender-4.5.14-linux-x64.tar.xz
(SHA-256 `9ba871ff2ecd36526b77432745980b7e6664ecd0c7ca11c48849073dcfe06da3`,
из `blender-4.5.14.sha256` там же). Версия закреплена в
`.github/workflows/blender-render.yml`; меняя её, проверьте сцену пробой —
в 5.x переименованы узлы неба и композитинга.

## Рендер — в GitHub Actions, не на сервере

Задача «Ролик студии — рендер Blender» (`.github/workflows/blender-render.yml`),
запуск вручную: формат `horizontal` (1920×1080) или `vertical` (1080×1920),
сэмплы, процент разрешения. 420 кадров идут в 20 задач через один, Cycles
на процессоре, 32 сэмпла и OpenImageDenoise. Последний шаг собирает MP4
(H.264, 30 к/с, ffmpeg) и коммитит ролик, превью и справку о рендере в
ветку `renders/devuz-studio`:

```sh
git fetch origin renders/devuz-studio
git show origin/renders/devuz-studio:renders/devuz-studio/devuz-studio-1920x1080.mp4 > devuz-studio.mp4
```

На боевой сервер рендер не отправлять (CLAUDE.md, «Сервер не собирает
сайт»).

## Проба у себя

```sh
python3 scripts/blender/devuz-studio/screens.py /tmp/screens
blender -b --factory-startup -P scripts/blender/devuz-studio/scene.py -- \
  --screens /tmp/screens --out /tmp/try/f_ --frames 1,130,300,400 \
  --percent 25 --samples 16
```

`--save scene.blend` сохраняет собранную сцену, `--vertical` — вертикальный
кадр.
