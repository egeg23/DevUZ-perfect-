# Пролёт для макета архбюро

Фотореальная сцена в Blender, собранная только кодом: вилла с бетонным
вторым этажом на консоли над стеклянной гостиной, терраса из камня,
бассейн, двор с деревом, мебель; для галереи ещё жилая башня с рёбрами и
павильон в парке. Руками в интерфейсе Blender ничего не делается.

Материалы, небо, мебель и деревья — Poly Haven, лицензия CC0
(https://polyhaven.com/license): `assets.py` качает их из API и сверяет md5.
Список и что где стоит — в `assets.py`.

## Кадры

| Что | Кадров | Где на сайте |
|-----|--------|--------------|
| `flight` | 180 | пролёт по прокрутке: генплан сверху (1–40) → облёт и спуск к фасаду (40–85) → низко над водой к открытой створке (85–150) → гостиная и двор (150–180) |
| `hero` | 192 | фон первого экрана: медленный проезд вдоль фасада, на сайте туда и обратно |
| `stills` | 12 | галерея проектов: вилла 1–6, башня 7–9, павильон 10–12 |

Горизонталь — 1920×1080, `--vertical` — 1080×1920 для телефона (тот же
путь камеры, обзор шире на треть). Экспозиция в пролёте поднимается,
когда камера входит в дом, как у настоящей камеры.

## Файлы

- `assets.py` — ассеты Poly Haven (обычный Python, до Blender).
- `scene.py` — сцена, камеры, рендер (`blender -b -P scene.py -- …`).
- `pack.py` — кадры в WebP и MP4 для сайта (Pillow, ffmpeg).

## Рендер — в GitHub Actions, не на сервере

Задача «Макет архбюро — рендер Blender» (`.github/workflows/blender-arhbyuro.yml`),
запуск вручную: что рендерить (`flight`, `hero`, `stills`), формат,
сэмплы, процент разрешения. Одна задача качает ассеты в кэш, 20 задач
рендерят кадры через один (Cycles на процессоре, 64 сэмпла и
OpenImageDenoise; ~6–7 минут на кадр 1920×1080 на 4 ядрах), последняя
жмёт их `pack.py` и коммитит в ветку `renders/arhbyuro`:

```sh
git fetch origin renders/arhbyuro
git checkout origin/renders/arhbyuro -- renders/arhbyuro/flight-horizontal/d
```

На сайт из ветки едут только `d/`, `m/`, ролики и кадры галереи; `hq/` и
`mhq/` — запас качества, в `public/` их не класть. На боевой сервер рендер
не отправлять (CLAUDE.md, «Сервер не собирает сайт»).

## Проба у себя

```sh
python3 scripts/blender/arhbyuro/assets.py /tmp/ph
blender -b --factory-startup -P scripts/blender/arhbyuro/scene.py -- \
  --assets /tmp/ph --shot flight --out /tmp/try/f_ --frames 1,85,150,180 \
  --percent 33 --samples 24
```

`--save scene.blend` сохраняет собранную сцену.

Blender **4.5.14 LTS**, как у ролика студии (`scripts/blender/devuz-studio`).
